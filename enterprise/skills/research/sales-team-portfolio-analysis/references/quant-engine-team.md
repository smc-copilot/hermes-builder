# 团队级量化引擎（Team Quant Engine）

> 本文件是 `sales-team-portfolio-analysis` 的内置量化内核，承载单客户评分、团队级结构诊断（含双HHI、涌现风险）的全部阈值/公式/评分标准。主 SKILL.md 的阶段二/三/四量化计算一律引用本文件，不另立口径。
> 来源：由原 `customer-portfolio-data-analysis`（v2.1.1-lite）蒸馏内嵌，数值与功能完全一致。个人级小样本规则与团队级双HHI口径在此统一。

## 核心原则
1. HHI 必算营收+毛利双口径（防"伪帕累托"）
2. 团队级 = 销售组织单元（100-1000家典型）；文中"团队"="部门"
3. 硬数据（ERP交易/回款）与软信号（关系/行业前景）区分标注
4. 每个量化指标配套管理动作
5. 合规与数据安全前置：受管制物项先合规；客户数据脱敏、仅内部使用

## 一、四支柱结构诊断

### 1.1 收入集中度 HHI
**公式**：$HHI = \sum_{i=1}^{N} s_i^2 \times 10000$（sᵢ=第i客户营收或毛利占比）。**算例**：8家营收150/120/100/80/60/50/30/20万（合计610），占比24.6/19.7/16.4/13.1/9.8/8.2/4.9/3.3%，平方和0.1631→HHI≈1631（需关注），CR1=24.6%（健康）。

⚠️ 营收HHI低+毛利HHI高=伪帕累托：大客户贡献大头营收但毛利<5%，团队在给他打工。

**判定**：<800过度分散 / 800-1000健康 / 1000-1800需关注 / 1800-2500中风险 / >2500高风险。
**红线**：CR1>30%预警（≤25-30%健康）；CR3>50%预警（危险>65%）；四维交叉=营收HHI+毛利HHI+CR1+CR3。

**样本量（结构性规则）**：HHI数学下界=10000/N，故5-9家时"<800/800-1000"档数学不可达、判定表失效：
- ≥10家：判定表正式生效
- 5-9家：HHI仅参考展示（标注下界10000/N），不作正式档位判定；集中度改用 CR1/CR3 主导 +📦长尾占比，增加定性权重
- 边界值：档位边界±3%内不单期判定，连续2期或结合CR1佐证

**双HHI（部门级专用）**：客户维度HHI（对单一客户依赖）+销售维度HHI（关键人风险），判定区间同上；"同时偏高"=两者均>1000→启动关键人预案（客户交接第二负责人）。
⚠️ 销售人数≤10时销售HHI下界=10000/N（3人≈3333/5人=2000），健康档可能不可达 → 改看Top1销售占比+客户交接机制，标注"小样本局限"。

### 1.2 层级金字塔
**四层**（占比和=100%，区间为参考；示范组合10/25/40/25=100%纺锤形）：
- 🏆战略标杆（行业领军+高交易额+深度绑定）5-15%；预警：>20%过度依赖/=0缺标杆
- ⭐核心大客户（规模大+稳定+多品类）20-35%；预警：<15%中坚不足
- 📊成长中型（有潜力+交易额中等）30-50%；预警：<20%梯队断层
- 📦小微长尾（规模小+浅层）15-30%；预警：>50%质量偏低

**形态**：纺锤形🟢（📊最厚）｜头重脚轻🔴（🏆+⭐>50%）｜底座过大🟠（📦>50%）｜梯队断层🔴（📊<20%）。
**分级优先级**：①上市/行业领军→≥⭐；②交易额前20%→≥⭐；③高增长赛道+增速>30%→≥📊；④交易额<中位数50%且无增长→📦（中位数=部门整体）；⑤其余综合。

### 1.3 行业多元化
**理想**：2-4主力赛道+2-3探索赛道。
**指标**：覆盖数≥5🟢/3-4🟡/≤2🔴；前2大行业占比<60%/60-70%/>70%；高增长赛道（AI算力/新能源/汽车智能化）占比>40%/20-40%/<20%；单一赛道最大占比<40%/40-60%/>60%。
⚠️ 2022-2023消费电子下行教训：行业多元化是风险缓冲核心。

### 1.4 增长动能
**指标**：增长客户占比（同比正增长）>60/40-60/<40%；新客户导入率（年度新客/总客户）>15/8-15/<8%（部门级新客管线目标≥5家）；C→A/B升级率>10/5-10/<5%；净客户价值增长率>15/5-15/<5%。

**净客户价值增长率定义**：净客户价值=客户群过去12个月毛利总额；增长率=（本期−上期）÷上期；与"客户资产增减值"同源。算例：上期500万→本期560万=+60万、+12%（预警档）。

**生命周期**（占比和=100%，参考区间，部门级）：培育期（新客<1年）20-30%｜放量期（1-3年）20-30%｜成熟期（>3年）30-40%｜衰退期<10%。培育期薄=未来断粮；衰退期重=当下流血。
**术语对应**：📊成长中型≈放量期≈成长期客户（同一类客户）。

## 二、二维评分卡（单客户评分）
**分数体系**：基础分=直接55+培育45=100；附加分+10为Bonus，**单独标注、不计入基础分与等级**；等级线S/A/B/C/D见2.6。

### 2.1 直接价值（55分）
| 子维度 | 满分 | 评分标准 |
|---|---|---|
| 交易额规模 | 20 | 占我司营收>15%=20；10-15%=15-19；5-10%=10-14；1-5%=5-9；<1%=1-4 |
| 毛利率贡献 | 20 | 有周转数据按GMROII主键：>150%=20；100-150%=14-19；50-100%=8-13；<50%=1-7。无周转按毛利率：>15%=17-20；10-15%=12-16；5-10%=7-11；<5%=1-6。毛利率恰15%归"10-15%"档 |
| 资金效率CCC | 15 | <45天=15；45-60=10-14；60-90=5-9；>90=1-4 |

**GMROII=毛利率×库存周转次数**（周转按成本口径COGS/平均库存精确）。独立分销CCC通常>90天为常态，不机械扣分。

### 2.2 培育价值（45分）
| 子维度 | 满分 | 评分标准 |
|---|---|---|
| 行业赛道成长性 | 15 | AI算力/新能源/汽车智能化=13-15；工控/安防稳定=8-12；成熟/萎缩=1-7 |
| 技术前沿性 | 15 | 前沿产品+Design-in机会=13-15；有研发无成果=8-12；纯制造/无研发=1-7 |
| 合作深度潜力 | 15 | 高层渗透+联合开发+多品类=13-15；采购+技术双通道=8-12；仅采购层=1-7 |

### 2.3 附加分Bonus（+10，不计入等级）
细分领域出货全国TOP3/全球TOP10=+5；行业领军/独角兽/原厂战略合作=+3；推进国产替代/新供应商/技术转型=+2。

### 2.4 二维象限（cutoff：直接≥30/55为"高"、培育≥25/45为"高"；Bonus不参与）
| 象限 | 特征 | 策略 | 预期占比 |
|---|---|---|---|
| S/A级（双高） | 直接≥30且培育≥25 | 专属资源、高层对接 | 15%（10-20%） |
| 现金牛 | 直接≥30且培育<25 | 标准化运营 | 20%（15-25%） |
| 潜力股 | 直接<30且培育≥25 | 培育周期+转化触发 | 25%（20-35%） |
| 长尾观察 | 双低 | 最低投入 | 40%（30-50%） |

### 2.5 六维评估卡（季度更新）
六维=直接3维（交易额20+毛利率20+CCC15）+培育3维（赛道15+技术15+合作15）=100（不含Bonus）。季度重打分，六维合计变动>10分→排查原因。

### 2.6 客户等级（单客户）
| 等级 | 基础分 | 典型象限 | 管理含义 |
|---|---|---|---|
| S | ≥85 | 双高 | 战略级投入 |
| A | 70-84 | 现金牛/潜力股强者 | 维持或培育 |
| B | 55-69 | 潜力股未转化 | 设转化触发 |
| C | 40-54 | 长尾观察/新客 | 最低投入 |
| D | <40 | 衰退风险 | 评估退出 |

C→A/B升级率=上年度C级客户中升A/B级数÷上年度C级总数。新客：直接价值计0、基础分=培育价值得分（满分45），标注"等级暂定"，落潜力股象限，6个月观察期。

## 三、团队客户群评分（100=20+15+15+15+20+15）
团队评分≠个体平均，涌现风险：①关键人风险（销售维度HHI）②客户归属重叠（**归属规则**：以CRM主负责人Owner为准；客户维度按客户整体、销售维度按主负责人）③梯队供给连续性。
| 维度 | 权重 | 说明 |
|---|---|---|
| 团队层级结构 | 20 | 全团队四层占比 |
| 团队收入集中度 | 15 | 双HHI（客户维度+销售维度；均>1000=同时偏高） |
| 团队行业多元化 | 15 | 跨客户聚合行业分布 |
| 团队增长动能 | 15 | 增长客户占比+新客管线总量 |
| 梯队连续性 | 20 | 放量期+新客能否覆盖成熟客户流失（健康：放量期客户数≥成熟期60%） |
| 标杆吸引力 | 15 | ≥2家行业标杆产生网络效应（转介绍/上下游） |

**综合等级（中文档位）**：卓越≥85·优质70-84·合格55-69·薄弱40-54·高风险<40。数值同单客户S/A/B/C/D，但对象不同、命名不同（避免混淆）。

## 四、健康区间总表
**灰区声明**：🟢与🟡之间为过渡带（复购60-70/退货3-5/DSO60-90/库存4-6/高价值10-15/流失20-30/超期10-15/样品15-20/试单20-30/毛利12-15）：进入即关注，不设硬阈值；🟡以上正式预警。
**对照关系**：本表为汇总口径；评分表"从严口径"。
**个人级小样本豁免（5-9家）**：CR1/CR3按个人级 CR版判定，不套用本表>50%线。

| 指标 | 🟢标准值 | 🟡预警线 | 🔴危险线 |
|---|---|---|---|
| 复购率 | 70-85% | <60% | <40% |
| 退货率 | <3% | >5% | >8% |
| 授权分销毛利率 | 15-25% | <12% | <8% |
| 账期DSO | <60天 | >90天 | >120天 |
| 库存周转 | >6次/年 | <4次 | <2次 |
| HHI/CR1/CR3 | 800-1000/≤25-30%/≤50% | >1000（1000-1800需关注、1800-2500中风险）/>30%/>50% | >2500/—/>65% |
| 主控切入率 | ≥20% | 10-20% | <10% |
| 梯队连续性（放量÷成熟） | ≥0.6 | <0.5 | <0.4 |
| 高价值客户占比（=S/A级，基础分≥70） | 15-25% | <10% | <8% |
| 流失风险客户占比 | ≤20% | >30% | >40% |
| 超期30天应收 | ≤10% | >15% | >20% |
| 样品→试单/试单→批量 | 20-40%/30-50% | <15%/<20% | <10%/<15% |

复购率长期>85%需核查单一需求依赖；行业差异校准详见 `health-benchmarks.md`。

## 五、三张表管理（部门版）
### 5.1 月度交易表（个人+部门；抓异常抓回款）
字段：客户（脱敏）|当月营收|上月营收|毛利|毛利率|回款|回款率|超期30天应收|占比|样品数|转单数|转单率|异常标记（来源：ERP+FAE工单）。
| 指标 | 关注点 |
|---|---|
| 营收 | 环比波动>20%排查 |
| 毛利 | 毛利率突降→压价/成本异常 |
| 回款 | 回款率<80%→现金流预警 |
| 超期应收 | >10%逐笔追催（操作线严于总表>15%，月度逐笔、季度走总表） |
| 样品转单率 | <15%→FAE效能或需求不真实 |

### 5.2 季度结构表（部门为主；排归因调资源）
字段：客户|六维六项得分|六维合计（100）|较上季变动|层级|象限|等级|生命周期（来源：月度表+2.5六维卡）。
| 指标 | 关注点 |
|---|---|
| 六维评估卡（2.5） | 六维合计变动>10分→排查 |
| HHI | 营收+毛利双算，环比升>200→集中恶化 |
| 金字塔形态 | 📊占比降→断层风险 |
| 生命周期分布 | 培育期降→断粮 |
| 行业分布 | 单一赛道升→集中 |

### 5.3 年度战略表（部门/管理层；算资产定方向）
字段：赛道（营收/占比/增速/高增长标记）+客户（12个月毛利/流失/新客/等级变动/主控状态）。
| 指标 | 关注点 |
|---|---|
| 赛道布局 | 高增长赛道占比是否提升 |
| 主控切入率 | <20%天花板锁死；10-20%预警；<10%危险 |
| 客户资产增减值 | 净值为负→资产缩水 |
| 客户留存率 | <70%→流失严重 |
| C→A/B升级率（2.6口径） | <10%→培育无效 |

**客户资产增减值口径（默认）**：客户资产=过去12个月毛利额；年度净值=Σ新客户（本年度首单）12个月毛利−Σ流失客户（上年有交易、本年无）上年12个月毛利；替换口径须显式标注。算例：新客85万−流失60万=+25万（增值）；新增仅35万则-25万（缩水）。

## 六、八大系统性不足与五处方
**主控切入率定义（全文统一）**：已实现主控芯片（SoC/主控MCU/CIS等平台锁定类）Design-in或量产的客户数÷活跃客户总数；"外围"（存储/PMU/分立）不计入。

| 不足 | 现象 | 动作 | 优先级 |
|---|---|---|---|
| 梯队断层 | 📊<20% | 补层：定向获取2-3家中腰 | 🔴 |
| 长尾过重 | 📦>50% | 瘦身：低效长尾标准化/线上化 | 🔴 |
| 大客户依赖 | CR1>30%或HHI>1800 | 分散化：拓中腰+CR1/CR3红线 | 🔴 |
| 主控缺位 | 只做外围 | FAE反推选型，强攻1-2个主控 | 🔴 |
| 伪繁荣占资源 | 大营收低毛利占满FAE工时 | 按毛利+回款重排，提价或降服务 | 🔴 |
| 回款风险 | 超期>10%、DSO拉长 | 账期分级+坏账追责，款到发货 | 🟠 |
| 开拓断层 | 季度新客0-1家 | 拓荒目标+线索池+新客单列考核 | 🟡 |
| 行业集中 | 单一赛道>60% | 跨赛道错配，选2-3探索 | 🟡 |

**五处方**：分散化（大客户依赖/头重脚轻）｜多元化（行业集中）｜补层（梯队断层，📊目标≥30%）｜瘦身（长尾/底座/伪繁荣）｜激活（动能不足/潜力/主控缺位，C→A/B升级）。
**映射**：主控缺位→激活+分散化；伪繁荣→瘦身；**回款风险不在五处方**，走账期管理专项。五处方不是五选一，往往两三个一起用。

## 七、三种典型模式
**头重脚轻（🏆+⭐>50%）**：加大📊层品类渗透，📊→⭐晋升目标（每销售每季度≥1家）；退出：连续2季大客户下滑且无替补。
**底座过大（📦>50%）**：长尾瘦身（年交易<中位数50%且无增长→标准化）；退出：人均管理>40家且📊转化<10%。
**行业单一（前2>70%）**：选1-2新赛道，用FAE能力跨行业迁移；退出：Design-in转化<5%持续4季。

> 六种更完整的客户群结构模式（倒三角/正三角/哑铃/纺锤/行业单一/高波动）与演化路径、行业基准，见 `portfolio-patterns.md`。

## 八、高价值信号
**硬信号（高置信）**：采购品类连续2季扩展；账期预付→月结；Design-in样品→小批量（将量产）。
**行业地位（中置信，需交叉验证）**：出货量细分TOP5；B轮以上融资；发布"全国产化"产品。
**关系深度（软信号）**：CEO/CTO主动联合技术验证；采购关键人变动（原厂背景）；研发投入占比连续3年>8%。

## 术语表
主控芯片=平台锁定类（SoC/主控MCU/CIS），区别于外围（存储/PMU/分立）｜主控切入率=已主控Design-in或量产客户数÷活跃客户｜Design-in=研发阶段纳入设计｜样品→试单→批量=漏斗三级｜CCC=应收+库存−应付（资金占用）｜GMROII=毛利率×库存周转｜DSO=应收/日均营收｜FAE=现场应用工程师（稀缺资源）｜钱包份额=客户同类采购中我方占比｜活跃客户=统计期内有交易客户｜Owner=CRM归属责任人｜放量期=成长期=📊成长中型（同一类客户）。
