# 团队资源调配决策框架（Team Resource Allocation）

团队级资源调配是本 skill 的核心输出之一——帮管理者看清"FAE/样品/高管/价格/新客开发"资源如何在团队内分配。所有分配比例均为建议性示范锚点（非评分阈值、非上游口径），实际按团队客户结构与 FAE 承载能力校准。

## 资源类型与分配逻辑

| 资源 | 稀缺性 | 分配逻辑 | 示范锚点 |
|------|--------|---------|---------|
| FAE 技术支持 | 高（最难扩） | 按客户层级价值分配，长尾走标准化 | 🏆25% + ⭐30% + 📊25% + 📦10% + 机动10% |
| 样品/Demo | 中 | 聚焦转化杠杆最大节点（晋升候选+P0未交易） | 优先📊→⭐候选 + P0未交易 |
| 高管拜访 | 低（时间有限） | 高层关系维护，只覆盖战略级 | 🏆季度1次 + ⭐半年1次 |
| 价格政策 | 中（利润让渡） | 战略性品类突破才用 | 主控切入机会客户 |
| 新客开发精力 | 中 | 确保管线不断，避免全员陷入存量 | 10-15% 精力 |

## 调配决策流程

1. **盘点资源**：当前 FAE 人数/工时、样品预算、高管可拜访次数
2. **计算缺口**：按 4b P0 清单 + 5d 行动清单折算所需资源 vs 可用资源
3. **优先级排序**：P0 客户优先；跨销售协同（见 cross-sales-synergy）资源可合并投放
4. **明确归属**：每项资源落到具体责任人 + 目标客户 + 完成信号
5. **季度复盘**：资源投入产出比（新品类/新客/升级数），连续2季低效资源重新配置

## 关键原则

- **资源跟随价值**：不是均分，是按客户层级与转化杠杆分配
- **长尾瘦身**：低效长尾占用 FAE 工时是团队最常见资源浪费（年交易额<中位数50%且无增长信号→标准化渠道）
- **机动池**：保留 10% 资源应对突发（大客户危机、跨销售协同机会）
- **能力匹配**：大客户给能力匹配的销售，避免资源错配（阶段一 1b）

## 常见错误

- FAE 被长尾客户占满，高价值客户响应慢（→ 长尾转标准化，量化释放精力）
- 样品无目标乱发，转化率低（→ 只投晋升候选+P0，设转单率跟踪）
- 高管拜访流于形式，无明确议题（→ 每次拜访设 1-2 个量化目标：品类切入/份额提升/危机化解）
- 新客开发精力为 0（→ 全员做存量，管线断裂，年度客户资产缩水）

## 输出模板

```
【资源调配决策】
一、资源盘点：FAE X人/月工时、样品预算X、高管可用X次/季
二、P0客户资源需求：Top 10-20 每家需要 FAE/样品/高管？
三、缺口分析：可用 vs 需求 → 缺口 X%（建议：机动池/优先级调整）
四、分配表：资源 → 客户/销售/动作/预期成果/完成信号
五、复盘指标：投入产出比、转单率、新客数、晋升数
```
