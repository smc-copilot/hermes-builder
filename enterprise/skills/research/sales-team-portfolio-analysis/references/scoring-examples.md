# 二维评分卡完整评分示例（Scoring Examples）

本文件提供量化引擎第二章「直接价值-培育价值二维评分卡」的完整打分示例，覆盖已交易客户与新开拓客户两类场景。所有示例数字为演示用。二维评分卡评分标准见 `quant-engine-team.md` 第二章。

## 一、完整打分步骤（已交易客户）

**打分五步**：① 取 ERP 交易数据（营收/毛利/账期/周转）→ ② 按 2.1 打直接价值 3 维 → ③ 按 2.2 打培育价值 3 维 → ④ 按 2.3 加附加分 Bonus → ⑤ 汇总基础分 + 等级 + 象限定位。

### 示例 1：汽车电子 Tier1 客户（高价值）

**交易数据**：年度采购 800 万（占我司营收 20%）、毛利率 18%、库存周转 8 次（GMROII = 18%×8 = 144%）、CCC 55 天。

| 子维度 | 依据 | 得分 |
|--------|------|:----:|
| 交易额规模 | 占我司营收 20% > 15% | 20 |
| 毛利率贡献 | GMROII=144%（100-150% 档） | 16 |
| 资金效率 CCC | 55 天（45-60 天档） | 12 |
| **直接价值小计** | | **48/55** |
| 行业赛道成长性 | 汽车智能化高成长赛道 | 14 |
| 技术前沿性 | 已量产多款前沿 ADAS 方案、有 Design-in 机会 | 14 |
| 合作深度潜力 | 采购+技术双通道已通，决策链渗透至研发总监 | 12 |
| **培育价值小计** | | **40/45** |
| 附加分 | 细分领域出货量全国 TOP3（+5）、正推进国产替代（+2） | +7 |
| **基础分（不含Bonus）** | | **88/100** |
| **总分（含Bonus）** | | **95/110** |

**判定**：基础分 88 → **S 级**；直接价值 48/55（≥30=高）+ 培育价值 40/45（≥25=高）→ **双高（S/A 级象限）**。策略：专属资源倾斜、高层对接。

### 示例 2：消费电子 ODM 客户（现金牛）

**交易数据**：年度采购 600 万（占 15%）、毛利率 6%、库存周转 12 次（GMROII = 6%×12 = 72%）、CCC 40 天。

| 子维度 | 依据 | 得分 |
|--------|------|:----:|
| 交易额规模 | 占我司营收 15%（10-15% 档上限） | 19 |
| 毛利率贡献 | GMROII=72%（50-100% 档） | 10 |
| 资金效率 CCC | 40 天（<45 天档） | 15 |
| **直接价值小计** | | **44/55** |
| 行业赛道成长性 | 消费电子成熟赛道 | 6 |
| 技术前沿性 | 纯组装无研发 | 3 |
| 合作深度潜力 | 仅采购层接触 | 5 |
| **培育价值小计** | | **14/45** |
| 附加分 | 无 | 0 |
| **基础分** | | **58/100** |

**判定**：基础分 58 → **B 级**；直接价值 44/55（≥30=高）+ 培育价值 14/45（<25=低）→ **现金牛象限**。策略：维持基础服务、标准化运营。GMROII 视角：毛利率 6% 看着低，但周转 12 次，单位资金产出不差——这就是"伪帕累托"反向案例（低毛高周转型仍是好现金牛）。

### 示例 3：小批量工业客户（潜力股）

**交易数据**：年度采购 80 万（占 2%）、毛利率 22%、库存周转 3 次（GMROII = 66%）、CCC 75 天。

| 子维度 | 依据 | 得分 |
|--------|------|:----:|
| 交易额规模 | 占我司营收 2%（1-5% 档） | 7 |
| 毛利率贡献 | GMROII=66%（50-100% 档） | 10 |
| 资金效率 CCC | 75 天（60-90 天档） | 7 |
| **直接价值小计** | | **24/55** |
| 行业赛道成长性 | 工控稳定增长赛道 | 10 |
| 技术前沿性 | 有在研产品、国产替代方案论证中 | 11 |
| 合作深度潜力 | 决策链渗透至研发经理，多品类扩展意向 | 11 |
| **培育价值小计** | | **32/45** |
| 附加分 | 正推进国产替代（+2） | +2 |
| **基础分** | | **56/100** |

**判定**：基础分 56 → **B 级**；直接价值 24/55（<30=低）+ 培育价值 32/45（≥25=高）→ **潜力股象限**。策略：设 6-12 个月培育周期，触发条件（Design-in 转小批量、月采购额突破 50 万）达成后重新定位。

## 二、新开拓客户评分（未交易）

**规则**：未交易客户无法计算直接价值（交易额/毛利率/CCC），直接价值标注"未交易，暂不可评"，**计 0 分**；仅评培育价值 3 维（满分 45），落**潜力股象限**，设 6 个月观察期。

### 示例 4：AI 服务器新客户（新开拓）

**信息**：行业龙头 AI 服务器厂商、完成 B+ 轮融资、自研主控板卡、正寻求国产算力芯片第二供应商。尚未成交。

| 子维度 | 依据 | 得分 |
|--------|------|:----:|
| 直接价值（交易额/毛利率/CCC） | 未交易，暂不可评 | 0 |
| 行业赛道成长性 | AI 算力最高成长赛道 | 15 |
| 技术前沿性 | 自研主控板卡、前沿技术产品在研、Design-in 机会明确 | 15 |
| 合作深度潜力 | 采购+技术双通道接触中，国产替代诉求强烈 | 13 |
| **培育价值小计** | | **43/45** |
| 附加分 | 行业领军（+3）、推进国产替代（+2） | +5 |
| **基础分（培育价值）** | | **43/100（仅培育价值，等级暂定）** |

**判定**：基础分 43（未交易口径）→ 落**潜力股象限**（直接价值=0<30、培育价值 43≥25），标注"等级暂定"；6 个月观察期内达成以下任一触发条件即重新打分：首单成交、Design-in 立项、月采购额连续 2 个月 >30 万。**注意**：新客基础分（43）与已交易客户基础分（88/58/56）**不可直接比较**——口径不同（未交易客户满分仅 45）。

## 三、六维评估卡示例（季度更新）

以示例 1 客户为例，六维合计 = 交易额 20 + 毛利率 16 + CCC 12 + 赛道成长性 14 + 技术前沿性 14 + 合作深度 12 = **88/100**。下季度若合作深度因关键人变动降至 8（新采购经理未建立信任），六维合计 = 84，变动 4 分（<10 分，不触发排查）；若同时毛利率降至 8（GMROII 72%，50-100% 档低端），六维合计 = 76，变动 12 分（>10 分，**触发排查**——定位原因：毛利率被压 or 周转下降）。

## 四、常见打分错误对照

| 错误 | 示例 | 正确做法 |
|------|------|---------|
| 用总分含 Bonus 判定等级 | 总分 95 → 判 S 级 | 基础分 88 → S 级；Bonus 单独标注 |
| 新老客户分数直接比较 | 新客 43 分 < 老客 58 分 → 新客价值低 | 新客满分 45，43/45 是高分；不可跨口径比较 |
| 毛利率档忽略 GMROII | 毛利率 15% 直接判满分档 | 有周转数据必须先算 GMROII 再按主键评分 |
| 档位内随便取分 | 良好档直接给 20 分 | 按插值规则：越接近健康上界取高分，±3 分内调整 |
| 忽略边界值规则 | HHI=1015 立即判预警 | 边界 ±3% 内不单期判定，连续 2 期或结合 CR1 佐证 |
