## 触发条件
"分析XX的客户群/XX销售客户群分析/评估我的客户/我的客户怎么样/客户群该怎么优化/精力该怎么分配"；或提交某位销售的客户画像清单（典型20-50个）要求评估/分析/改进建议。
**排他判定**（须同时满足）：①分析对象=单个销售的个人客户群（非团队/部门）；②核心诉求=二次开发+开拓价值+精力分配（非单纯评分排名）。否则路由：团队/部门（含2人团队：拆2个本skill并跑或按 sales-team 样本量降级）→sales-team-portfolio-analysis；单客户画像→customer-profiling；原始交易流水（TSV/CSV）→sales-transaction-diagnostics。

## 输入规范
1. 销售信息（必需）：姓名、部门/团队、负责行业/区域
2. 画像清单（必需）：典型20-50个客户；每客户：公司信息（名称/行业/规模/市场地位）+交易状态（已交易/新开拓）+已交易（历史、年交易额、毛利率、账期、合作品类、合作深度、增长态势）或未交易（接触阶段、意向品类、预估规模、接触来源）
3. 我司背景（建议）：定位、核心产品线、授权品牌
4. 内部数据（可选强烈建议）：ERP订单/毛利/账期/退货、CRM拜访、FAE工单

**MVP 最小输入**：每客户仅4必填——公司名称、所属行业、交易状态、年交易额（已交易）或意向品类+接触阶段（未交易）；其余缺失=信息不足（取保守最低分并标注）。客户≥10家可启动MVP（定性为主+量化可算维度照常输出）；完整字段=深度模式。**禁止因字段不全拒绝分析**。
**信息不足**：缺失取保守最低分并标"信息不足"；无交易额按客户规模×行业平均采购率估算标"推算"；10-19家正常执行；5-9家小样本走引擎§三 CR版（HHI仅参考）；<5家提示补充样本。

## 核心原则
1. 改善导向：目的不是打分排名，是帮销售看清"精力该往哪投"
2. 双时间切面：同时捕获"当下利润贡献"（直接价值）与"未来价值迁移"（培育价值）
3. 已交易/未交易分离：已交易评二次开发，未交易评开拓价值
4. 量化+叙事交融，不机械分区
5. **量化口径唯一来源**：本skill的**客户价值评分与结构健康基准**类阈值（二维分值、HHI/CR区间、金字塔健康占比、八大不足判定线）以内置 `references/quant-engine-individual.md` 为唯一权威源；仅可定义**运营层判定**（开拓优先级映射/精力分配比例/钱包份额机会分档），须显式标「运营层」；引擎输出标「量化口径」；两者不混用/不换算/不替代
6. 合规前置：受管制物项/受限实体客户，先合规再商业

**适用范围**：默认语境=半导体/电子元器件分销（主控切入/Design-in/FAE为行业术语，见引擎术语表）；其他行业替换为对应品类/设计链表述，通用逻辑（品类扩展/份额提升/关系深化）不变。

## 五阶段工作流

### 阶段一：画像解析与分类
**1a 字段提取**（★=MVP必填）——
- 已交易：名称★ 行业★ 规模 市场地位 年交易额★ 毛利率 账期/DSO 合作品类数 合作深度 增长态势 风险信号
- 未交易：名称★ 行业★ 规模 市场地位 意向品类★ 接触阶段★ 预估规模 接触来源 风险信号

**1b 交易状态分类**：
| 状态 | 定义 | 后续路径 |
|---|---|---|
| 已交易-活跃增长 | 近12月有交易且同比正增长 | 二次开发 |
| 已交易-稳定维护 | 近12月有交易但持平 | 二次开发（侧重激活） |
| 已交易-静默/下滑 | 近12月下滑或>6月无交易 | 流失预警 |
| 已交易-已流失 | >12月无交易 | 挽回成本评估 |
| 已交易-合规退出 | 订单大幅萎缩/归零，但根因为公司业务合规管控加严后的主动退出决策（非销售不力、非客户流失） | **不计入流失/失败**；风险表标"主动风控"，绩效评价去污名化 |
| 未交易-深度接触 | 已送样/已报价/技术验证中 | 开拓价值（高） |
| 未交易-初步接触 | 已拜访/已建立联系 | 开拓价值（中） |
| 未交易-线索 | 仅基本信息，未实质接触 | 开拓价值（低） |

> **⚠️ 订单归零归因纪律**：凡客户订单大幅萎缩/归零，**先确认是否合规退出再归因销售**——默认归因销售失败会污染个人绩效评价。判定合规退出后：该客户从"流失预警"改挂"合规退出"状态、不计入八大不足中的"开拓断层/流失"，并在报告中补「合规环境说明」。

**1c 四维标签**：行业标签（消费电子/汽车/工控/医疗/通信/新能源/AI算力/其他）+价值象限（引擎§2.4二维象限：已交易按直接×培育；未交易按培育分落潜力股/长尾观察；本skill不自定义阈值）+合作状态（1b）+拓展潜力（品类可拓展/份额可提升/关系可深化/暂无空间）。

**1d 潜在客户快速筛选（未交易客户粗筛前置）**：当未交易客户数较多（≥10家）且字段信息有限时，先按 `references/potential-customer-screening.md` 的3维简化评分（规模资质5+芯片需求价值5+赛道增长5=15分）做粗筛，输出四层分级（立即攻坚/重点培育/常规跟进/标准维护），再对Top客户进入阶段三的精评。已交易客户不适用此步。

### 阶段二：已交易二次开发机会评估
**2a 客户价值评分（量化口径）**：加载引擎§2.1/§2.2——直接价值55分+培育价值45分→基础分、等级S/A/B/C/D、二维象限。定性观察维度（不另行计分，仅识别2c机会）：品类覆盖、关系层级、决策链渗透、增长态势、账期质量。**本skill不设第二套单客户评分**。
**2b 钱包份额（运营层机会分档）**：公式=我司交易额÷客户总采购额。≥50%主力（防守防渗透深化绑定）｜30%-50%重要（扩品类争份额）｜10%-30%补充（**重点拓展，最大杠杆区间**）｜<10%边缘（需突破核心品类）。
**2c 机会矩阵**：品类扩展（有需求未供→新增品类额，🔴）｜份额提升（钱包10-30%，每+10%增量，🔴）｜关系深化（仅触达采购→进技术/高层，🟠中高）｜主控切入（仅外围→Design-in，行业特定，🔴）｜账期优化（付款好但账期短→放账换份额，🟡中）。

> **品类扩展/主控切入的品牌匹配（NEW）**：当评估"品类扩展"或"主控切入"机会、需要给出"推什么品类/品牌"时，加载 `skill_view(name="distributor-advantage-brand-dictionary")`，用字典的"品类→品牌反查表"和"定位速查总索引"匹配独立分销优势品牌（结合客户价格/技术定位筛选档位），与授权品牌并列输出并标「独立分销」。
**2d 建议卡**（Top5机会客户）：
```
### [客户名] 二次开发建议卡
当前状态（交易额/毛利率/品类/钱包份额/价值评分·量化）｜核心机会｜建议动作（做什么/找谁/推什么品类）｜品牌匹配（授权品牌 + 独立分销品牌，后者加载 distributor-advantage-brand-dictionary 反查，标「独立分销」）｜预期增量（目标品类单价×预计年用量×毛利率，推算标"推算"）｜所需资源（FAE/样品/高管拜访/价格政策）｜时间窗口（如Q3选型窗口期）｜风险及应对
```

### 阶段三：未交易开拓价值判断
**3a 培育价值评分（量化口径）**：加载引擎§2.2的45分制；未交易客户直接价值计0、基础分=培育分、等级暂定、落潜力股象限（引擎§2.4/§2.6）。本skill不重述评分标准。
**3b 开拓优先级（运营层映射，分值来自引擎§2.2）**：
| 培育价值分（引擎） | 接触阶段 | 优先级 | 动作 |
|---|---|---|---|
| ≥35分 | 深度接触 | 🔴P0 | 集中资源推进首单 |
| ≥35分 | 初步接触 | 🟠P1 | 加速推进送样/报价 |
| ≥35分 | 线索 | 🟡P2 | 建立实质联系推进拜访 |
| 25-34分 | 深度接触 | 🟠P1 | 持续跟进等转化触发 |
| 25-34分 | 初步接触 | 🟡P2 | 常规维护不过度投入 |
| 25-34分 | 线索 | 🟢P3 | 标准化跟进 |
| <25分 | 任意 | 🟢P3 | 最低投入标准化跟进 |
> 分值分档（≥35/25-34/<25）为**运营层映射**（非引擎评分口径）；引擎调整分制时按自检重跑复核。
**3c 判断卡**（P0/P1）：
```
### [客户名] 开拓价值判断卡
客户概况（行业/规模/地位/培育分·量化）｜接触现状｜开拓价值判断（值不值得投+理由）｜建议动作｜转化触发条件（什么信号加大投入）｜预计转化周期（参照样品→试单→批量节奏，推算标"推算"）｜退出信号（何时放弃/降级）
```

### 阶段四：客户群结构诊断（量化调用内置引擎）
**执行**：加载引擎§一（四支柱）+§三（个人客户群评分）执行全部量化计算；本skill不复制公式/阈值/健康基准，仅定义产出项。数值一律标「量化口径」：
- 4a 收入集中度：HHI营收+毛利双算、CR1/CR3；5-9家按引擎CR版（HHI仅参考）
- 4b 层级金字塔：四层占比+形态判定；未交易单独计入新客管线（4d），**不并入金字塔占比**
- 4c 行业多元化：覆盖数、前2大占比、高增长赛道占比
- 4d 增长动能：增长客户占比、新客管线（数量+质量）、生命周期
- 4e 个人客户群评分：引擎§三输出100分制+中文档位（卓越/优质/合格/薄弱/高风险）

### 阶段五：资源投入与行动方案
**5a 精力分配（运营层；分类轴=交易状态×层级；区间参考，示范组合32/28/17/10/13=100%）**：
| 类别（互斥，每客户唯一落类） | 占比 | 动作 |
|---|---|---|
| A 已交易-活跃增长 × 引擎层级 🏆/⭐ | 30-35% | 深化合作/品类扩展/防竞对 |
| B 已交易-成长 × 引擎层级 📊 | 25-30% | 伴随成长/锁定增量/推主控切入 |
| C 未交易P0/P1（潜力股象限） | 15-20% | 加速转化争首单 |
| D 已交易-稳定 × 引擎象限 现金牛 | 10% | 维持服务不过度投入 |
| E 已交易-低效（📦长尾）或未交易P2/P3 | 10-15% | 标准化服务释放精力 |
> 符号来源：🏆/⭐/📊/📦=引擎§1.2层级标签；现金牛/潜力股=引擎§2.4象限标签；只消费不定义。
**5b 八大不足自查（量化口径）**：加载引擎§六八大不足+五处方，按引擎判定标准逐项输出"是否存在+处方"；本skill不重述阈值。
**5c 季度行动清单**（Top5按P0-P4）：
```
| 优先级 | 行动 | 目标客户 | 预期成果 | 所需资源 | 完成信号 |
```
**5d 下季度优化目标**：HHI（如1800→1200）、📊占比（如18%→30%）、新客管线（如+5家深度接触）、钱包份额（针对10-30%区间）。

## 口径标注约定（强制）
| 标注 | 含义 |
|---|---|
| 量化口径 | 数值/判定直接来自内置引擎 `quant-engine-individual.md` 输出（二维分值、HHI/CR、金字塔占比、八大不足、客户群评分） |
| 运营层 | 本skill自定决策阈值（3b分档/5a比例/2b分档），不来自引擎 |
| 推算 | 输入缺失估算（规模×行业采购率、预期增量、转化周期） |

量化口径与运营层**不混用/不换算/不替代**；报告每个数值须可归属。引擎升级后按自检重跑。
