# 设备-芯片映射说明（已迁移）

> **本文件已退役**：原"20类电子产品设备与芯片映射表"已统一迁移至 `industry-chip-dictionary` 字典 skill（38 行业完整芯片品类清单，唯一权威源），不再在本 skill 内维护映射数据。

## 当前用法

调用 `skill_view(name="industry-chip-dictionary")` 获取：

1. **正向表**（行业 → 芯片品类）：原厂产品线映射到目标行业时，查该行业所需的芯片品类
2. **反查表**（品类 → 适用行业）：阶段二"芯片→设备反向匹配"——某品类能匹配哪些行业客户，直接查反查表
3. **行业指纹品类表**：快速识别原厂产品线对应的下游行业归属

## 阶段二反向匹配示例

原厂产品线含"高精度ADC + 隔离器 + 功率器件" → 查字典反查表：
- 高精度ADC → 工控、工业设备、医疗、电表、新能源、电源模组
- 隔离器 → 工控、工业设备、电源模组、医疗、新能源、储能、电表、轨道交通、军工
- 功率器件（IGBT/MOSFET）→ 电源模组、新能源、储能、电动工具、两轮车、白色家电、工控、工业设备

交集 = 工控/工业设备/新能源/储能/电源模组 → 原厂目标行业重点候选。
