# 第一批：欧美日品牌完整版图（10 个）

> 数据采集：2026-09-15。每个品牌含：芯片细分品类（全量清单）、主要应用电子产品、市场定位/产能/排名。

## 1. TI（德州仪器 Texas Instruments）

**芯片细分品类**

| 大类 | 细分类别 |
|------|---------|
| 信号链 | 运算放大器、比较器、电流感测放大器、ADC/DAC 数据转换器、接口芯片（RS-485/CAN/USB）、逻辑芯片、传感器（温度/电流/光学） |
| 电源管理 | 电池管理（燃料计/充电器/保护）、DC-DC 开关稳压器、LDO、AC-DC、栅极驱动、LED 驱动、电源监控 |
| 嵌入式处理器 | MCU（MSP430/SimpleLink/C2000 实时控制）、DSP、Sitara 处理器、汽车处理器（Jacinto/TDAx ADAS） |
| 其他 | DLP 数字光处理（投影/车灯）、计算器/教育技术 |

**主要应用电子产品**：工业自动化、汽车电子（ADAS/电池管理/车载信息娱乐）、消费电子（**Soundbar 等音频设备**、家电、手机周边）、通信基站、企业系统。

**市场定位/产能/排名**：定位**高端**（工业/汽车）+ **中高端**（消费），全品类平台型，料号超 8 万个。产能 IDM 垂直整合（自建晶圆厂+封装厂），规模全球最大梯队之一。排名：**模拟芯片全球第一**（约 18–20%）、放大器全球第一（约 29%）、电源管理全球第一（约 21%）、数据转换器全球第二（次于 ADI）、全球半导体前十。

## 2. ADI（亚德诺 Analog Devices）

**芯片细分品类**

| 大类 | 细分类别 |
|------|---------|
| 数据转换器 | 高精度 ADC/DAC（医疗/工业/通信/雷达） |
| 放大器 | 高精度运放、仪表放大器、差分放大器 |
| 电源管理 | LDO、DC-DC、电池充电、PMIC、BMS 电池监视（LTC681x）、SIMO PMIC |
| 传感器 | MEMS（加速度/陀螺仪/压力/温度） |
| 射频与微波 | RF IC、混频器、锁相环 |
| 接口/隔离 | 数字隔离器、接口转换、精密基准 |

**主要应用电子产品**：工业设备（占 44.7%）、汽车电子（占 29.8%，BMS/电动化）、消费电子（占 13%）、通信（占 12.5%）、医疗设备、航空航天/军工。

**市场定位/产能/排名**：定位**高端**（高精度、高可靠性、高毛利标杆）。产能半 IDM（自研产能超 50%，其余委外），并购凌力尔特、美信后完成信号链+电源全栈布局。排名：**数据转换器全球第一**、模拟芯片全球第二（约 13%）、产品型号超 7.5 万、客户超 12.5 万。

**市场定位/产能/排名**：定位**中高端**（车规功率与传感强）。产能**全产业链垂直整合**（SiC 从晶锭→晶圆→模块封装），供应稳定性强。排名：**汽车 ADAS CIS 全球第一**（市占超 60%）、功率分立器件全球第二（约 8.7–14%）、SiC 全球第二（2024 营收约 8.2 亿美元）、功率半导体全球第二。

**市场定位/产能/排名**：定位**中端为主**（STM32 生态极强）+ **高端**（SiC/车规）。产能 IDM，意大利卡塔尼亚建 8 英寸 SiC 综合产业园，APMS 业务群产品超 15000 种。排名：**SiC 全球第一**、功率半导体全球第三、MCU 全球前五、模拟芯片全球第五（约 5%）、全球半导体前十。
