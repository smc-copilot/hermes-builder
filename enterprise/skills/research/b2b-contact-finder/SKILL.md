# 企业全维度联系窗口采集器

## 技能概述

对指定企业进行全网无死角的联系窗口检索，自动进行全网搜索，聚合来自工商登记、企业官网、招聘平台、社交媒体、专业数据库、新闻舆情等全渠道的联系方式，输出结构化、可验证的企业联系人信息清单。

## 输入参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `company_name` | string | ✅ | — | 企业全称 |
| `credit_code` | string | ❌ | — | 统一社会信用代码，提高精确度 |
| `depth` | enum | ❌ | `deep` | 检索深度：`basic`（基础）/ `standard`（标准）/ `deep`（深度） |
| `include_executives` | bool | ❌ | `true` | 是否包含高管个人联系方式 |

## 触发条件

用户输入匹配以下模式时自动激活：
- "查找 xxx 公司的联系人"
- "xxx 公司的业务窗口"
- "xxx 公司联系方式"
- "找 xxx 公司的采购/销售/HR"
- "xxx 公司怎么联系"
- "帮我找 xxx 公司的负责人"
- "找一下 xxx 公司的关键决策人"

## 执行流程

### Step 1: 企业基础信息确认

1. **工商公示系统核验**：通过搜索引擎检索国家企业信用信息公示系统，确认企业存续状态和基本信息
2. **基础数据获取**：获取统一社会信用代码、法定代表人、注册地址等基础数据
3. **多源交叉核验**：同时检索天眼查、企查查、爱企查等第三方平台的公开信息进行补充确认，解决单一平台数据更新滞后或公示系统访问限制导致的信息不准问题
4. **别名与曾用名识别**：从信用信息中提取企业曾用名、历史品牌名、集团子公司关系，确保后续搜索不遗漏

**搜索策略**：
```
web_search: "{company_name} 工商信息 天眼查"
web_search: "{company_name} 企查查 企业信息"
web_search: "{company_name} 爱企查"
web_search: "site:gsxt.gov.cn {company_name}"
```

> ⚠️ **分公司/分支机构名称陷阱**：中国大陆的分公司（branch office）工商注册名称中的总公司部分，可能与用户熟知的品牌名不同。例如用户说"研华科技（中国）有限公司深圳分公司"，但实际工商注册名可能是"北京研华兴业电子科技有限公司深圳分公司"（不同的法律主体）。**必须先确认总公司的实际工商注册全称**，再用"[注册全称]+分公司+[城市]"搜索分支机构的工商信息。仅用品牌名搜索分公司极易漏查。

> ⚠️ **公司未找到的处理**：若经过企查查、天眼查、爱企查、国家企业信用信息公示系统、招聘平台、社交媒体等全渠道检索后仍无结果，必须在报告中明确标注"❌ 未找到"并列出已覆盖的检索渠道清单，同时给出可能的原因分析（名称有误/尚未注册/已注销/非正式称呼）。不要编造或猜测联系方式。

### Step 1.5: 企业命名变体识别（关键前置步骤）

中国企业普遍存在**名称歧义**问题，需在正式搜索前识别所有变体：

- **母公司 vs 办事处/分公司**：用户可能用"深圳XX有限公司"指代某集团的深圳办事处，而该办事处并非独立注册实体。搜索时需同时检索母公司+"{city}办事处/分公司"
- **曾用名/品牌名 vs 注册名**：如"北京研华兴业电子科技有限公司"是"研华科技（中国）有限公司"的曾用名/关联实体
- **同名不同企**：可能存在名称近似但完全无关的公司（如"深圳市研华科技有限公司"与工控领域的"研华科技 Advantech"无关）
- **集团公司 vs 子公司**：大型集团下可能有多个子公司各自注册

**操作**：在 Step 1 确认后，生成一份 `{company_name}` 的变体清单（正式注册名、曾用名、品牌名、各城市办事处名），后续搜索交替使用。

### Step 2: 工商注册信息采集

1. **年报联系信息**：检索国家企业信用信息公示系统年报中的联系电话和邮箱
2. **第三方平台补充**：查询企查查/爱企查/天眼查的工商基本信息（注册电话、传真）
3. **企业年报提取**：查阅企业年报，提取"企业联系电话""财务联系电话"
4. **历史号码聚合**：检索该企业的历史联系电话集合，包含不同年份年报中登记的电话，识别号码变更轨迹
5. **高管个人注册电话识别**：识别工商信息中法定代表人或经办人留存的个人手机号，单独标签归类

**搜索策略**：
```
web_search: "{company_name} 年报 联系电话"
web_search: "{company_name} 工商注册 电话 邮箱"
web_search: "{company_name} 法定代表人 {legal_representative}"
web_extract: 天眼查/企查查/爱企查企业详情页
```

### Step 3: 企业官网扫描

1. **关键页面扫描**：访问企业官网，重点扫描以下页面：
   - `/contact`、`/contact-us`（联系我们）
   - `/about`、`/about-us`（关于我们）
   - `/team`（团队介绍）
   - `/careers`、`/jobs`（加入我们）
   - `/news`（新闻中心）
2. **邮箱地址提取**：提取所有邮箱地址（info@、sales@、hr@、pr@ 等）
3. **联系电话提取**：提取所有联系电话（座机、400热线、手机）
4. **高管介绍页**：识别并提取高管介绍页中的联系方式
5. **邮箱域名推断**：基于收集到的邮箱后缀（如 @company.com），推断可能的邮箱组合模式（如 `firstname.lastname@company.com` 或 `firstname@company.com`），用于后续高管邮箱猜想
6. **行业垂直平台产品页**：对于工控/制造业企业，搜索其在工控网(gongkong.com)、维科网(ofweek.com)等行业平台的产品页面，这些页面通常包含400热线、办事处地址和销售邮箱
7. **企业年报/ESG报告PDF**：上市公司（尤其是台湾/港股上市公司）的英文年报PDF通常在 investor relations 页面公开下载，内含全球各办事处的完整地址和电话；ESG/可持续发展报告则包含供应商窗口和CSR联系方式
8. **eRMA/售后服务系统**：制造业企业的在线报修系统(eRMA)通常包含各区域服务中心的完整地址、电话和传真

**搜索策略**：
```
web_search: "{company_name} 官网"
web_search: "site:{company_domain} 联系我们"
web_search: "site:{company_domain} contact"
web_search: "{company_name} site:gongkong.com"  (工控/制造业企业)
web_search: "{company_name} annual report PDF investor"  (上市公司)
web_search: "{company_name} ESG sustainability report contact"  (上市公司)
web_search: "{company_name} eRMA service center"  (制造业企业)
web_extract: 官网首页 + /contact + /about + /team
```

### Step 4: 招聘网站信息采集

1. **主流招聘平台检索**：在 Boss直聘、51JOB、智联招聘、猎聘等平台检索该企业的招聘信息
2. **HR 联系信息**：提取 HR 联系人、公司电话、HR 邮箱等信息
3. **岗位页深度抓取**：除 HR 联系方式外，提取技术部门主管、业务线负责人等作为关联联系人（基于招聘描述中的"汇报对象"或"面试官"信息，标注为弱相关/待验证）
4. **JD 附加信息**：提取 JD 中的企业总机号码、公司地址、统一邮箱等字段

**搜索策略**：
```
web_search: "{company_name} 招聘 Boss直聘"
web_search: "{company_name} 招聘 智联招聘 HR"
web_search: "{company_name} 猎聘 招聘"
web_search: "site:zhipin.com {company_name}"
web_search: "site:liepin.com {company_name}"
```

### Step 5: 社交媒体与职业社交平台挖掘

1. **LinkedIn**：检索公司主页和员工列表，提取关键岗位人员信息
2. **脉脉**：检索企业员工档案中的联系方式
3. **微信公众号**：检索企业公众号，提取菜单栏和推文中的联系方式
4. **微博/抖音/小红书**：检索企业官方账号中的联系方式字段
5. **企业微信线索**：检索企业微信公开名片、客服微信号（如有公开）
6. **电商平台**：在天猫、京东企业店铺页中提取客服电话、售后服务邮箱

**搜索策略**：
```
web_search: "{company_name} LinkedIn"
web_search: "{company_name} site:linkedin.com"
web_search: "{company_name} 脉脉"
web_search: "{company_name} 微信公众号"
web_search: "{company_name} 京东旗舰店 客服电话"
web_search: "{company_name} 天猫旗舰店 联系方式"
```

### Step 6: 专业数据库查询

1. **B2B 联系人数据库**：检索 ZoomInfo / Apollo.io 等 B2B 联系人数据库
2. **海关数据平台**：如适用，查询进出口业务联系人
3. **行业 B2B 平台**：在阿里巴巴（1688）等平台提取店铺联系方式
4. **行业特定平台**：检索目标企业所在行业的特定数据平台（如建筑行业的企业信用平台、食品行业的许可证公示平台）
5. **上市公司公告与年报**：对于上市公司，通过巨潮资讯网、深交所、上交所等平台，检索定期报告、招股说明书、联系方式变更公告，提取董秘办电话、投资者关系邮箱、总部电话等权威联系方式

**搜索策略**：
```
web_search: "{company_name} site:zoominfo.com"
web_search: "{company_name} site:apollo.io"
web_search: "{company_name} 1688 阿里巴巴"
web_search: "{company_name} 巨潮资讯 年报" (上市公司)
web_search: "{company_name} site:cninfo.com.cn" (上市公司)
```

### Step 7: 新闻舆情与公开信息检索

1. **搜索引擎综合检索**：企业名称 + 联系人/电话/邮箱 等关键词组合
2. **新闻媒体**：从报道中提取高管姓名和可能的联系方式
3. **招投标公告**：提取项目联系人
4. **行业论坛/贴吧/股吧**：检索相关线索
5. **政府采购与招投标平台**：在各地政府采购网、公共资源交易平台检索企业中标/投标公告，提取项目中留的联系人姓名、手机号、座机
6. **行业展会/活动**：检索行业会议、博览会、培训活动的参会名录、演讲嘉宾名单、会场联系方式手册
5. **行业门户产品页**（高价值来源）：行业门户（如工控网 gongkong.com、OFweek、仪表网等）的企业产品页常包含**办事处级别的联系方式**（地址、电话、邮箱），这些信息在官网上可能不易找到
6. **消费电子垂直平台**（高价值来源）：消费电子领域的垂直媒体和探厂平台是企业联系方式的富矿区：
   - **充电头网**（chongdiantou.com）：充电/电源行业最权威的垂直媒体，品牌页包含企业联系电话、办公地址，常有多个业务手机号
   - **探厂高手**（tanchang.cn）：工厂探访报道平台，包含企业地址、电话、分公司/工厂信息
   - **什么值得买**（smzdm.com）：品牌入驻信息、产品评测中的企业联系方式
   - 搜索策略：`"{company_name}" OR "{brand_name}" site:chongdiantou.com`、`"{brand_name}" site:tanchang.cn`

**搜索策略**：
```
web_search: "{company_name} 联系人 电话"
web_search: "{company_name} 联系人 邮箱"
web_search: "{company_name} 中标公告 联系人"
web_search: "{company_name} 招标 项目负责人"
web_search: "{company_name} 展会 演讲"
web_search: "{company_name} 政府采购 中标"
web_search: "site:gongkong.com {company_name} 联系电话 地址"
web_search: "site:ofweek.com {company_name} 联系方式"
web_search: "site:chongdiantou.com {company_name} OR {brand_name}"
web_search: "site:tanchang.cn {brand_name}"
```

### Step 8: 高管定向挖掘（`include_executives=true` 时执行）

1. **高管名单获取**：从工商信息中获取高管姓名列表
2. **LinkedIn/脉脉检索**：检索高管个人职业档案
3. **搜索引擎定向搜索**：`"{高管姓名} + {企业名称} + 联系方式"`
4. **企业邮箱推断**：基于 Step 3 获得的邮箱域名模式，推断高管邮箱（姓名拼音组合）
5. **行业会议/活动**：检索高管参会或演讲信息
6. **学术/专业文章**：检索高管在知网、万方等学术平台的论文署名信息（通常附带机构邮箱）
7. **司法诉讼文书**：在裁判文书网、执行信息公开网查询高管作为当事人/代理人的联系方式（⚠️ 标注：来源为司法公开，使用需额外合规审查）

**搜索策略**：
```
web_search: "{executive_name} {company_name} 联系方式"
web_search: "{executive_name} {company_name} LinkedIn"
web_search: "{executive_name} {company_name} 演讲 会议"
web_search: "{executive_name} {company_name} 论文 知网"
web_search: "{executive_name} site:linkedin.com"
```

### Step 9: 数据聚合与输出

#### 9.1 数据清洗
- 对所有采集到的联系方式进行去重
- 按来源渠道分类标注（工商/官网/招聘/社交/数据库/新闻等）

#### 9.2 数据验证机制
- **格式校验**：电话号码（座机/手机/400正则）、邮箱格式验证
- **逻辑校验**：去除明显不合理的号码（如空号、仅含数字的占位符等）
- **时效标注**：对每个联系方式的发布时间、数据来源时间进行标注，优先展示近1-3年的最新数据
- **可追溯性**：每个联系方式附带来源 URL 或平台 ID，方便人工核查

#### 9.3 可信度评级

| 等级 | 说明 |
|------|------|
| ⭐⭐⭐ 高可信 | 来自官方渠道（工商年报、企业官网、上市公司公告），且为近1年数据 |
| ⭐⭐ 中可信 | 来自权威第三方平台（天眼查/企查查/招聘平台），或官方渠道但超过1年 |
| ⭐ 低可信 | 来自社交媒体、论坛、推断邮箱等，需人工验证后使用 |

### 输出路径与文件管理

**双格式同步输出（强制执行）**：每份联系窗口报告完成后，必须同步输出以下两种格式：
1. **Markdown (.md)**：完整版报告，保存到 `/data/hermes/workspace/exports/`
2. **Word (.docx)**：通过 `markdown-conversion` skill 中的 `md2docx.py` 脚本自动转换生成，保存到同一目录

**文件名命名规范（强制执行）**：统一采用 `生成年月日_报告名称` 格式。
- 格式：`YYYYMMDD_报告名称.md` 和 `YYYYMMDD_报告名称.docx`
- `报告名称`：取企业全称 + "联系窗口报告"，去除特殊字符
- 示例：
  - ✅ `20250805_深圳凌健智能科技有限公司_联系窗口报告.md`
  - ✅ `20250805_深圳凌健智能科技有限公司_联系窗口报告.docx`
  - ❌ `深圳凌健智能科技有限公司_联系窗口报告.md`（旧格式，缺少日期前缀）

**DOCX自动转换协议**：
1. 先保存 `.md` 文件到 `/data/hermes/workspace/exports/`
2. 加载 `skill_view(name="markdown-conversion")` 获取转换指引
3. 运行转换脚本：
   ```bash
   python3 /data/hermes/skills/productivity/markdown-conversion/scripts/md2docx.py \
     /data/hermes/workspace/exports/YYYYMMDD_报告名称.md \
     /data/hermes/workspace/exports/YYYYMMDD_报告名称.docx
   ```
4. 验证 `.docx` 文件生成成功（`ls -lh` 确认文件大小 > 0）
5. **展示点击下载链接（强制）**：`.docx` 生成并验证非空后，除上述展示要求外，必须在结果对话框中展示 Word 报告的**点击下载链接**，让用户直接点击下载：`MEDIA:/data/hermes/workspace/exports/YYYYMMDD_报告名称.docx`。**空文件防护**：展示链接前必须用 `ls -lh` 或 `wc -c` 确认 `.docx` 非空（> 0 字节）；若为 0 字节或生成失败，不得展示下载链接，须如实报告失败原因。
6. 若 `terminal` 工具不可用（WebUI环境），将自包含转换脚本写入 workspace，告知用户可离线执行

**转换失败处理**：若 `.docx` 生成失败（脚本报错、python-docx 未安装等），应：
- 在最终输出中明确告知用户：".md 文件已就绪，.docx 转换失败：[原因]，您可手动运行转换脚本"
- 不得因 .docx 失败而阻塞 .md 文件的交付

## 常见陷阱与经验

1. **企业名称歧义是最大障碍**：用户提供的公司名可能不是精确的工商注册名。大型集团（如研华/Advantech）的各地办事处常被俗称为"深圳XX有限公司"，但实际上并非独立法人。必须先在 Step 1.5 做名称变体识别。
2. **同名不同企**：企查查/爱企查可能返回名称近似但完全无关的公司。需通过经营范围、法定代表人、注册资本等维度交叉验证，而非仅看名称。
3. **web_extract 后端限制**：当前环境若后端为 DuckDuckGo，`web_extract` 无法提取页面内容。此时应加大 `web_search` 搜索密度，用 site: 限定查询来间接获取页面信息。**curl 直取兜底（已验证 2026-08）**：当搜索命中率耗尽且目标为中国中小型企业信息站（水滴点评 shuididp.cn 等）时，可尝试直接抓取：
   ```bash
   curl -sL --max-time 25 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36" "<企业详情页URL>"
   ```
   关键经验：① 首次请求通常能绕过验证码拿到完整 HTML，**务必一次抓到并保存到本地**（`-o /tmp/x.html`），二次请求大概率被验证码拦截（返回 `<title>请输入你的验证码</title>`）；② 用 python 正则去标签后按关键词行过滤（经营范围/注册/股东/统一社会/参保），`<meta name="Description">` 常直接含注册资本/法人/成立时间；③ 反爬阈值随 IP 变化，失败不要重试同一 URL，改用搜索引擎摘要。
4. **行业门户是高价值信息源**：gongkong.com、ofweek.com 等行业门户的企业产品页常包含办事处级别的电话、地址、邮箱，有时比官网更完整。
5. **PDF 年报/产品目录**：上市公司的年报 PDF 和企业的产品目录 PDF 常通过搜索引擎可检索到，其中包含完整的办事处列表和联系方式。搜索时加 `filetype:pdf` 限定。
6. **多地址模式**：中国制造型企业普遍存在"注册地址 ≠ 工厂地址 ≠ 业务办公地址"的三址分离现象。注册地址来自工商系统，工厂地址来自探厂报道/招聘信息，业务办公地址来自行业平台/官网。三种地址需分别标注，不可混为一谈。典型来源对应：爱企查→注册地址，充电头网/探厂高手→业务办公地址，环评公告/消防验收→工厂地址。
