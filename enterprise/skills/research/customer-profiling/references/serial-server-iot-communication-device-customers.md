# 串口服务器/工业物联网通信设备制造商客户备忘

> NEW，2026-08 上海卓岚（ZLAN）案例。适用于：串口服务器（RS232/RS485转以太网）、串口转以太网芯片/模块、4G/5G DTU、Modbus/MQTT网关、远程IO控制器、串口转WiFi/LoRa/Zigbee模组与终端、串口转光纤/工业交换机等工业联网设备制造商。此类客户是芯片分销商的常见客群，BOM 散而广（多型号小批量），适合"多品类打包"服务。

## 识别信号

- 官网产品线出现「串口服务器」「DTU」「Modbus网关」「远程IO」「串口转以太网」「工业接口转换器」等关键词（典型域名如 zlmcu.com）
- **技术型创始人**：自研嵌入式TCP/IP协议栈（如卓岚ZLIP）、自研串口转以太网芯片/模块 → 研发驱动、FAE依赖强、决策权高度集中于老板
- 集研发-生产-销售一体（集团化，生产主体ISO9001认证）→ 制造型客户确认
- 常见参展：IOTE物联网展、MWC上海；销售渠道：京东/淘宝旗舰店 + 英文站（如 zlan-iot.com）→ 内外销并行
- **双重角色检测**：多数这类公司既做芯片/模块级产品（串口转以太网芯片）又做整机（串口服务器/网关）——芯片/模块制造需求（晶圆/封测，非分销业务）与终端产品芯片采购需求分列，品牌匹配聚焦后者

## 芯片映射（交叉类别：工控3 + 物联网类6 + 网络设备18 + 通信模组19）

- **核心（★★★）**：工业级MCU、RS-485收发器、PMU/LDO/DC-DC、NOR Flash、TVS/ESD保护、隔离器件（光耦/数字隔离）、蜂窝通信模组（4G/5G）

## 切入策略

1. **切换成本排序**：NOR Flash/电源（成本最低）→ RS-485收发器（刚需+进口替代主力）→ TVS → 通信模组/DDR
2. **新品BOM窗口**：5G RedCap工业网关（如卓岚ZLAN8309-5G，2026年量产）是供应商导入最佳时点——移远RedCap模组、DDR、Flash 等新料需求明确。检测方式：搜索「公司名+新品/IOTE/展会新闻」
3. **FAE技术方案驱动**：替代料验证 + 降本测算，直击技术型创始人/总工程师（决策权高度集中，决策周期短，<3个月）
4. **已合作模式**：历史电商供货散料（电源/逻辑/RS-485/光耦/保险丝）是已跨壁垒的硬证据 → 升级为 BOM级打包方案商
