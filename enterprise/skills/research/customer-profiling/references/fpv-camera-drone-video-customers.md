## 二、典型客户特征

- **深圳/珠三角聚集**（RunCam深圳龙岗、Caddx深圳）
- 业务模式：**自有品牌研发 + 国际贸易 + 兼任大厂代理**（RunCam = DJI FPV品类中国总代理，三位一体）
- 中小规模：注册资本500万级、员工50~150人【推测】、研发驱动（多为国家高新技术企业）
- 产品迭代极快：模拟→数字HD→4K运动相机→夜视多线并进，**新品BOM窗口频繁**
- 采购特征：小批量多频次、单价低（几十~几百元）、产品型号多（10+款产品线）
- 常为跨境电商/多语言官网销售，欧美为主要消费市场

## 三、芯片映射（FPV相机/图传/运动相机）

| 芯片类别 | 需求程度 | 备注 |
|----------|:--------:|------|
| CIS图像传感器 | ★★★ | **高端SONY原厂直采不可触**（如ScopeCam 2用SONY CMOS）；中端晶相/格科微可切入 |
| 图像处理SoC/ISP | ★★★ | 模拟链路ISP+OSD；数字链路编解码SoC，Sigmastar星宸强匹配 |
| MCU（32位） | ★★★ | 相机控制、参数配置、OSD叠加，恒烁Zbit |
| NOR Flash（SPI） | ★★★ | 固件/启动/OSD配置存储，全产品线必备，**切换成本最低（首推切入品类）** |
| PMU（电源管理） | ★★★ | 多路供电（sensor/SoC/图传/显示），上海贝岭/应能微 |
| TVS/ESD保护 | ★★★ | 接口防护、EMC合规，应能微 |
| DDR | ★★☆ | 数字图传/4K运动相机图像缓存，Nanya南亚 |
| HDMI/接口芯片 | ★★☆ | 4K相机HDMI输出（如RunCam 6），Parade谱瑞 |
| WiFi/BT模组 | ★★☆ | App连接/固件升级，博流智能 |
| 5.8G无线SoC | ★★☆ | 模拟图传射频方案潜在替代，AMICCOM笙科 |
| 音频芯片 | ★★☆ | 运动相机录音 |

**切入顺序（已合作品类扩展）**：NOR Flash → PMU → TVS → MCU → DDR（绑定数字图传/4K新品）→ 中端CIS（验证周期长，放后期）

## 四、DJI生态直采禁区（关键约束）

- 兼容DJI FPV系统的数字图传（如RunCam Link Wasp，遥控器直连DJI生态）= **专有协议/原厂方案，分销商不可触及**——与AI边缘计算"核心SoC不可触及"（见 device-chip-mapping.md AI边缘计算专项）同型
- 高端CIS（SONY）原厂直采
- 切入策略：**聚焦外围器件，不挑战主力**（与竞品格局"不挑战主力"原则一致）
