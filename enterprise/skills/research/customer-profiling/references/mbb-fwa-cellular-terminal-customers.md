# MBB/FWA 蜂窝数据终端制造商客户备忘

> 适用：4G/5G MiFi（移动热点）、CPE（客户前置设备）、Dongle（USB数据卡）、ODU（室外单元）等 MBB/FWA 蜂窝数据终端，及 Tracker/OBD/WiFi模块 等 IoT 终端的 ODM/OEM 制造商。典型客户：伟文无线（WeWins）、美格智能（002881）、广和通、移远（部分终端线）等。

## 识别信号

1. **产品关键词**：MiFi / CPE / Dongle / ODU / FWA / 移动热点 / 随身WiFi / 数据卡 / MBB 蜂窝数据终端
2. **官网定位语**："carrier-grade reliability"、"Fixed Wireless Access"、"over X million devices shipped worldwide"（累计出货量常以千万台计）
3. **客户结构**：海外运营商（印度/印尼/巴基斯坦/非洲/中东/欧洲/北美）为终端客户，公司自己出海或代工；国内运营商（移动/联通/电信）短名单/合作单位
4. **资质组合**：高新技术企业 + 专精特新 + 瞪羚企业 + 科技型中小企业（出海 ODM 常见组合）
5. **组织特征**：深圳研发总部 + 异地（成都/西安）软件研发中心 + 制造基地（常向惠州/东莞等珠三角制造带迁移），员工 100~500 人、研发占比 70%+

## 客户类型判定

**制造型客户**（默认分支）。有明确的自研产品线 + ODM/OEM 量产制造，非贸易型、非平台型。注意：部分客户工商登记为「批发业/信息传输业」，仍按制造型处理（与 EMS/PCB 代工厂同理，以官网实际产品线为准）。

## 交叉芯片映射（字典无单一行业行）

交叉使用「通信模组(19) + 网络设备(18) + 物联网类(6)」三行业行：

| 产品 | 核心芯片 |
|------|---------|
| MiFi（移动热点） | 蜂窝SoC + 射频前端 + PMU + 存储 + WiFi/BT |
| CPE（客户前置设备） | 蜂窝SoC + 射频前端 + 以太网PHY + DDR + PMU |
| Dongle（USB数据卡） | 蜂窝SoC + 射频前端 + eMMC/NOR |
| ODU（室外单元） | 蜂窝SoC + 高功率射频 + POE电源 + TVS |
| Tracker/OBD | MCU + 通信模组 + 传感器 + 电池管理 |
| WiFi模块 | WiFi SoC + Flash + 晶振 |

## ⭐ 核心洞察：授权品牌直供（区别于多数客户的"补充层"定位）

这是本类客户**最关键的切入判断**：其**主控平台（蜂窝 SoC）和射频前端可能正是我方授权品牌**。

- 蜂窝 SoC 供应商格局：高通、**紫光展锐（UNISOC，我方授权）**、MTK、ASR 翱捷
- 射频前端：Skyworks、Qorvo、**慧智微、承芯（我方授权）**

当客户主控平台为我方授权品牌（如紫光展锐 5G 平台）时，切入定位从"外围器件补充层"升级为**"授权品牌直供"**——能供应核心平台本身就是强切入凭证，这是罕见的、可正面切入核心 BOM 的机会。这与其他设备类客户（AI边缘计算/汽车座舱/IP摄像头等）"核心 SoC 原厂直采不可触及、只能做外围"的默认结论**相反**，判定前必须确认客户主控平台归属。

## 切入顺序

1. **低切换成本试单**：恒烁 NOR Flash（固件存储）→ 应能微 TVS（接口/天线保护）
2. **核心 BOM 打包**：紫光展锐蜂窝 SoC + 慧智微/承芯射频前端 + Nanya/KIOXIA 存储 + 上海贝岭/应能微 PMU，以打包方案（综合降本 + 供应连续性）而非单品竞价切入
3. **绑定新品 BOM 窗口**：5G CPE/ODU 新品导入期纳入存储（DDR/eMMC）与 PMU

## 采购窗口信号

- **4G→5G 平台升级**：新产品需要射频前端、大容量存储、PMU 新 BOM
- **制造基地新建/迁移**：如惠州新设制造主体（供应链正重新搭建），是新供应商导入窗口
- **国产化替代**：紫光展锐平台占比提升带动国产料采购比例上升

## ⚠️ 陷阱

1. **同名实体区分（高危）**：检索会命中多家名称相近但非同主体的公司，必须逐家核验统一社会信用代码/法人/地址。本类案例：伟文**无线通讯技术**（南山，2500万，法人吴学伟，本客户）vs 伟文**科技**（宝安，200万，法人彭霞芬，电子元器件生产）vs 威文科技——三家并存，销售团队极易混淆。
2. **法人口径差异**：百度百科主条目可能滞后（记"宋继海"），企查查/爱企查/分公司百科为最新口径（吴学伟）。以企查查最新为准，百科冲突时标注说明。
3. **营收推算**：非上市 ODM 营收未披露，用「同赛道龙头（如美格智能 002881）营收 ÷ 员工数类比」推算，须标注推导估算 + 置信度。
4. **ODM 价格敏感**：同行净利率极低（美格智能约 3.8%），毛利薄、账期谈判空间有限，须以打包方案提供综合降本，而非单品让价。

## 评分要点

- **市场地位**：出海 ODM 通常非全球龙头，落"细分领域前20/区域性"档（约 10/20 分），不虚高
- **加分项 1（出货量 TOP3/TOP10）**：无第三方排名数据支撑时判 ❌，不因"累计出货 2000 万台"这类自述定性给分
- **加分项 3（平台转型/国产化/新供应商）**：4G→5G 升级 + 国产平台 + 新基地供应链重构 = 满足，+2
- **典型评分**：中型 ODM 落 **B 级（55-74）**，但因授权品牌匹配度极高，"切入价值高于分数所体现"

## 案例：伟文无线（WeWins，2026-09）

- 2007 年成立，注册资本 2500 万实缴，台港澳与境内合资，深圳南山总部 + 成都研发中心 + 惠州制造基地（2026 新设）
- 主营 4G/5G MiFi、CPE、Dongle、ODU + Tracker/OBD/WiFi模块，全球累计出货 2000 万+台
- 客户：沙特 STC、阿曼 Omantel、也门 VORTEX 等海外运营商
- 决策链：唐鹏（董事/经理，惠州制造主体法人，供应链核心决策人）→ 吴学伟（实控人，最终审批）
- **评分 B 级 70/110**：基本面 32/55 + 匹配度 25/30 + 潜力 11/15 + 加分 2
- 切入：恒烁 Flash + 应能微 TVS 试单 → 紫光展锐 SoC + 慧智微射频打包攻核心 BOM → 绑定 5G CPE/ODU + 惠州新基地窗口
