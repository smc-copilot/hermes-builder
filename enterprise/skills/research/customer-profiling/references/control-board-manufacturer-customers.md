# 单片机控制板/控制器制造商客户画像备忘（NEW，2026-08）

> 适用客户类：以「单片机软件开发 + 智能控制电器 + 电机设备/自动化控制设备」为经营范围关键词签名的小微制造企业。典型代表：龙港市佳帝电子科技有限公司（2026-08实战）。
> 此类客户遍布温州（龙港/乐清）、慈溪、宁波、佛山、中山等轻工制造带，是中国电子制造业的"毛细血管"，会反复出现。

## 1. 客户类识别（经营范围关键词签名法）

当公司经营范围同时包含以下关键词 → 判定为单片机控制板/控制器制造商（制造型）：

| 关键词 | 含义 |
|--------|------|
| 单片机软件开发 / 嵌入式软件开发 | 有MCU固件开发能力（自研） |
| 智能控制电器技术开发 | 面向家电/设备端的控制板 |
| 电机设备加工/销售 | 电机控制器方向 |
| 自动化控制设备加工/销售 | 自动化控制部件方向 |
| 电子产品研发、设计、加工 | 可能含ODM/OEM属性 |

⚠️ 与「贸易型」区分：有"研发/设计/加工/软件开发"字样 = 制造型；仅"销售/批发" = 贸易型（走贸易型分支）。

## 2. 组织与规模特征（普遍模式）

- 注册资本 < 500万，参保人数 < 20人，未融资
- 成立5~15年，持续存续但无扩张信号
- 老板（法人/总经理）一人拍板，决策链极短
- 无官网或官网不可发现；BOSS直聘/1688企业信用页是主要公开窗口
- 无公开财务数据 → 营收/采购规模用员工数推算（见 non-listed-company-estimation.md）

## 3. 产品推断逻辑

| 经营范围信号 | 推断产品 | 置信度 |
|------------|---------|:------:|
| 单片机软件开发 | 各类MCU控制板（固件自研） | 高 |
| 电机设备 | 直流无刷/步进/交流电机控制器 | 中-高 |
| 自动化控制设备 | 小型自动化设备控制箱/控制部件 | 中 |
| 智能控制电器 | 家电/小家电/温控/调速控制板 | 中 |

目标市场（推断）：本地及周边整机厂配套——印刷包装机械、小家电、礼品机械、电动工具。

## 4. 芯片需求与品牌匹配

| 芯片品类 | 需求 | 推荐品牌 |
|---------|:----:|---------|
| MCU/单片机 | ★★★ | 恒烁Zbit（32位MCU）、杭州国芯（工业IoT SoC） |
| NorFlash（固件存储） | ★★★ | 恒烁Zbit |
| PMU/电源管理 | ★★★ | 上海贝岭、华源智信 |
| 功率器件（MOSFET/IGBT） | ★★★ | 士兰微、应能微 |
| 通信接口（RS-485/CAN） | ★★☆ | 杭州思泰微 |
| 光耦/隔离 | ★★☆ | 应能微 |
| 传感器接口/运放 | ★★☆ | 杭州思泰微 |
| TVS/ESD | ★★☆ | 应能微 |
| 显示驱动 | ★★☆ | ILITEK |
| 无线模块 | ★★☆ | 博流智能、移远通信 |

## 5. 评级预期（已合作模式）

- 基本面弱（注册资本/人员/融资三低）→ 基础分通常 30~40 分
- 业务匹配度高（MCU/PMU/功率与我司品牌线对口）→ 维度二可拿 15/30 上下
- 典型落点 **C级（<55分）**
- ⚠️ C级解读：单体价值低但**获客成本几乎为零**（已合作）、订单频次高、品类扩展边际成本极低——定位「小额高频、稳定产出」型，严禁因C级放弃维护已合作客户

## 6. 销售策略要点

1. 切入顺序按切换成本从低到高：**NorFlash → PMU → MCU → 功率器件**
2. 打包方案话术："把3家供应商合并成1家"（降采购管理成本+综合单价），而非单纯卖货
3. 差异化：正品保障 + FAE选型/烧录支持 + 稳定供货（小微厂最怕断料）
4. 账期：维持短账期/货到付款，放量前观察回款记录——小微企业资金链抗风险能力弱
5. 直接对接老板本人（法人兼总经理），无需复杂决策链

## 7. 实战案例：龙港市佳帝电子（2026-08）

- 2014年成立（曾用名：苍南县佳帝电子科技有限公司），注册资本100万，参保11人
- 法人潘其立（执行董事兼总经理），监事薛思川
- 评分36/110 C级；芯片需求核心 = MCU + NorFlash + PMU + 功率器件
- 关键检索技巧：**行政区划变更地区必须用新旧双地名检索**（苍南县→龙港市）——旧地名命中2018年温州市科技局名单，当前名检索无此记录（详见 SKILL.md 第1c步）
