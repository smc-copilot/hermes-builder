# 电源/充储电 OEM/ODM 制造客户画像备忘（NEW，2026-09）

> 适用于：移动电源（充电宝）、充电器/充电头（含 GaN 氮化镓）、户外储能电源（便携式电站）、智能排插、无线充电器、新能源周边配件的 **OEM/ODM 代工制造商**。典型代表：蓝之洋科技（Anker 主力供应商）、奥海科技、海能实业等。

## 识别信号

1. **主营产品线签名**：移动电源 + 充电器 + 户外储能 + 智能排插 + 无线充电的组合（而非单一品类），对外品牌知名度低但强调"OEM/ODM/代工/面向全球品牌"
2. **大客户背书**：宣称"Anker 主力供应商 / 深度战略合作"、服务"全球 50+ 知名品牌"、获评"出口 100 强"——Anker（全球充电宝销量第一、纯设计+销售全部外包代工）的供应体系成员是强信号
3. **资质组合**：国家级高企 + 专精特新中小企业 + BSCI/Sedex/MFi（苹果配件）+ ISO9001/ISO14001 + 多国出口认证
4. **招聘 JD 技术栈暴露**（jobui 高价值源）：电子工程师要求"DC-DC 电路原理图设计、电芯选型、BOM 制作与 PCB 评审、EMC 优化""PD3.0/3.1、QC2/3/4/5 快充协议、BUCK/BOOST/BUCKBOOST/H 桥升降压电路、无线充 QI2.0/MPP"；嵌入式软件要求"移动电源控制逻辑、QC/PD 协议"——证实**自研+制造**（非纯组装）
5. **多基地制造**：珠三角总部（深圳宝安等）+ 内地产业园（江西遂川等）双基地，量产基地成本敏感

## BOM 签名实证（关键，2026-09 充电头网）

> 移动电源芯片供应商格局是判断客户 BOM 和授权品牌切入点的硬情报：

- **22.5W 以下快充移动电源**：单芯片 SoC 方案（一颗集成快充协议），主流供应商 **英集芯（Injoinic）、智融**
- **22.5W 以上 USB PD 快充移动电源**：MOS 外置升降压方案，多电芯串/并联，国产芯片供应商 **南芯（Southchip）、士兰微（Silan）、宝砾微**
- **推论**：我方授权品牌**士兰微**已在大功率移动电源 MOS 外置升降压方案中有位置——这是最直接的切入依据，可作为"已用国产料→顺势扩品类"的突破口

## 核心约束

1. **主控/快充 SoC 原厂直采不可触及**：移动电源主控（英集芯/南芯/智融）、GaN 充电器主控为原厂直采，我方定位"外围国产电源料补充层"，不正面竞争
2. **电芯非分销业务**：移动电源 BOM 中电芯占比 40~50%（最大头），属战略采购，非芯片分销商业务
3. **进口料国产替代空间大**：高端 AC-DC/GaN/模拟（TI/PI/MPS）有国产替代诉求，代工毛利薄→价格极敏感
4. **成本是首要赢单因素**：代工企业元器件价格敏感度极高，国产替代是核心诉求

## 切入顺序（低切换成本→高价值）

```
TVS/ESD、NorFlash（打入 AVL）→ MOSFET、PMU/DC-DC（士兰微/贝岭/应能微）→ 快充协议芯片、AC-DC（华源智信/贝岭）→ 隔离器、储能 BMS（绑定新品导入期）
```

## 评分要点

1. **注册资本≠真实规模（强制）**：此类 OEM 客户常注册资本低（如蓝之洋 500 万）但实际体量大（月产 350 万台、年营收推测 15~30 亿）。**量化评分"规模与营收"维度优先采信制造数据（月产能/B2B 平台工厂面积）而非仅看注册资本**，蓝之洋该维度给 10 分而非按注册资本给 1~4 分
2. **"Anker 主力供应商"≠行业领军**：加分项 2（行业领军/独角兽/原厂重点客户）**不自动触发**——Anker 是品牌商非原厂，"主力供应商"是客户关系不是市场地位，行业领军是奥海科技
3. **无第三方出货量排名**：加分项 1（全国 TOP3/全球 TOP10）通常无权威数据支撑，判 ❌（Anker 的全球第一份额不可转移至代工厂）
4. **移动电源芯片国产化是行业普遍趋势**：非客户独有战略声明，加分项 3（国产化替代）不因"BOM 中国产芯片占比高"自动触发——但该事实应在"业务匹配度"维度体现
5. **典型评级 B 级**：基本面受注册资本低/无融资/无自有品牌拖累（30~35/55），但业务匹配度高（25/30 左右），综合 65~72 分 B 级

## 风控备忘

电源 OEM 客户常见"司法案件数较多 + 税务信用 A 级"并存（蓝之洋 175 条案件 + 税务 A 级）。按税务 A 级更强原则判"中等（待核实）"，**首单款到发货或月结 30 天**，核实案件方向（原告/被告）后再放宽。注意排除相似名干扰（"溪之洋""蓝橙"等）。
