## 3. DMS/ODM芯片需求盲区实例

研华除自有品牌产品（工业主板ARK/AIMB系列、工控机UNO系列等）外，还设有 **Applied Computing (DMS)** 部门，为客户提供定制化设计制造服务。这意味着：

| 需求来源 | 自有品牌 | DMS/ODM | 合计影响 |
|----------|---------|---------|---------|
| 芯片品类覆盖 | 6大类核心+5大类扩展 | 同品类但增加用量+定制芯片 | 总量上浮30~50% |
| FAE支持需求 | 标准方案 | 定制化方案支持需求更强 | 需要更强的FAE能力 |
| 品牌选择 | 高 | 客户指定品牌倾向明显 | BOM品牌固化 |

**教训**：仅分析自有品牌产品会低估芯片总需求30%以上。在阶段二检索中，务必检查客户的商业模式是否包含「DMS/ODM/Design-in Service」等关键词。

## 6. 搜索策略备忘录

本案例执行过程中的搜索发现：

| 搜索策略 | 有效/无效 | 说明 |
|----------|----------|------|
| 中文全称 + "工商信息" | ❌ 无效 | 大量垃圾SEO站点干扰 |
| 英文品牌名 + "revenue employees" | ✅ 有效 | 英文搜索结果干净，信息密度高 |
| 英文品牌名 + "annual report PDF" | ✅ 有效 | 直接获取官方财务数据 |
| site:qcc.com + 品牌名 | ✅ 有效 | 企查查站内搜索 |
| site:baike.baidu.com + 品牌名 | ✅ 有效 | 百度百科结构化信息 |
| 英文品牌名 + "investor" | ✅ 有效 | 直达官方投资人关系页面 |
| 负面信息："[公司名] 诉讼 纠纷" | ⚠️ 有噪声 | 需要交叉验证，很多无关结果 |

**建议策略优先级（中文背景客户）：**
1. 先搜英文品牌名查全球数据（如果品牌有英文名）
2. 用 site:baike.baidu.com 查中文公司百科
3. 搜"英文品牌名 annual report PDF" 获取财报
4. 搜"英文品牌名 investor" 访问官方IR页面
5. 最后用中文全称补全负面信息检索
