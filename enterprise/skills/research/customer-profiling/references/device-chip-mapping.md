## 1. 车灯/尾灯方案客户特殊说明（NEW，2026-08 汇昕微案例）

> 当客户为车灯方案商/车灯模组客户时（如极海×汇昕微 G32A1445 贯穿式汽车尾灯方案），除字典「汽车电子」行业通用品类外，聚焦以下品类：

| 芯片类别 | 需求程度 | 备注 |
|----------|----------|------|
| LED驱动IC | ★★★ | 多路PWM调光，贯穿式尾灯可达192+通道 |
| CAN/LIN收发器 | ★★★ | 车灯通信标配：一路LIN+一路CAN、CANFD最高8Mbit/s |
| 车规PMU | ★★★ | LDO/BUCK低Iq电源，支持软启动/EN/PG |
| TVS/ESD保护 | ★★★ | 车规接口防护/EMC |
| NOR Flash | ★★☆ | 方案固件/配置存储，切换成本最低，首推切入 |
| MOSFET | ★★☆ | LED功率开关 |
| 隔离器件 | ★★☆ | 车规信号隔离 |

> ⚠️ **主控MCU常为原厂联合方案核心（如极海G32A1445），需避让不竞争**——切入策略聚焦方案BOM外围器件（存储/PMU/LED驱动/TVS），与AI边缘计算客户"核心SoC不可触及"同理。
> 两轮车智能化（无感解锁）方向额外关注：BLE（★★★）、MCU（★★★）、PMU（★★★）、高精度ADC/传感器接口（★★☆）。
> 详见 `references/design-house-value-added-distribution-customers.md`。

## 2. 电子纸（E-Paper）显示模组特殊说明

> 当客户产品为电子纸模组时，除字典「显示设备」行业通用品类外，还需关注：

| 芯片类别 | 需求程度 | 备注 |
|----------|----------|------|
| NOR Flash | ★★★ | 存储波形驱动数据/固件，所有电子纸模组必备 |
| MCU | ★★★ | 智能电子纸的系统管理 |
| DDR | ★★☆ | 带OS的电子纸平板/教育本 |
| WiFi/BT | ★★☆ | 无线通信 |

> **关键约束**：电子纸Driver IC需通过E Ink认证——推荐ILITEK奕力前必须先确认认证状态。电子纸膜片（E Ink供应）是BOM最大成本项但分销商不可切入。
> 详见 `references/epaper-display-supply-chain.md`。

## 3. 电力巡检机器人与电力AI设备

> 覆盖：变电站/换流站/输电线路巡检机器人（轮式、四足、轨道式）、电力专用无人机、智能传感器终端、物联网网关、智能工器具柜、电力AI边缘计算盒子等。典型客户为服务南方电网/国家电网的科技型中小企业，以"AI算法+硬件"项目制交付。

| 芯片类别 | 需求程度 | 备注 |
|----------|:--------:|------|
| 工业级MCU | ★★★ | 机器人运动控制、传感器数据采集、网关主控，需宽温(-40~85°C) |
| 边缘AI SoC/NPU | ★★★ | 本地AI推理（图像识别/缺陷检测/红外分析），如巡检机器人的视觉AI核心 |
| 图像传感器（CIS） | ★★★ | 可见光+红外热成像双光巡检，工业级/安防级CMOS |
| 通信模组（4G/5G/NB-IoT） | ★★★ | 巡检数据回传、远程控制、电力物联网上行通信 |
| WiFi/BLE模组 | ★★★ | 设备本地配网、调试、短距通信 |
| PMU（电源管理） | ★★★ | 工业级宽压供电、多路电压域、电池供电机器人 |
| 电机驱动 | ★★★ | 机器人行走/云台转动/自动门控制 |
| 传感器（非图像） | ★★★ | 温湿度、局放、气体、振动等多模态电力传感器 |
| 存储芯片（DDR/Flash） | ★★☆ | AI推理缓存、固件存储、巡检日志记录 |
| 射频前端芯片 | ★★☆ | 通信模组的PA/LNA/滤波器配套 |
| Sub1G/LoRa无线SoC | ★★☆ | 电力物联网长距离低功耗场景（输电线路监测） |
| 模拟芯片（高精度ADC） | ★★☆ | 传感器信号采集，电力测量级精度 |
| GNSS定位芯片 | ★★☆ | 无人机/户外巡检机器人定位导航 |
| 电池管理芯片 | ★★☆ | 锂电池供电的巡检机器人/无人机 |

> **特殊注意事项**：
> - 电力行业元器件对**宽温(-40~85°C)**和**EMC抗扰度**要求严格，消费级芯片通常不适用
> - 服务央企客户（南网/国网）的科技供应商面临**国产化替代压力**，国产MCU/通信模组/PMU是强需求
> - 这类客户多为10~100人的技术型中小企业，**采购量小但单品价值高**（工业级元器件单价远高于消费级），适合FAE驱动的技术型分销模式
> - 硬件交付为**项目制**（非批量流水线），单次采购量小但频次高，需要灵活的小批量供应能力
> - 切入路径：MCU+通信模组+PMU三件套组合覆盖最核心需求，辅以CIS和传感器

## 4. AI边缘计算设备

> 覆盖：边缘计算盒子（Edge Computing Box）、AI服务器、AI加速卡、AI智能工作站、算法一体机、大模型一体机等产品。典型客户为英码科技、图为科技、研华（边缘AI线）、凌华科技、智微智能、创通联达等。这类客户的核心AI SoC（算能/昇腾/寒武纪/海思）通常为**原厂策略直采，分销商无法切入**，但外围配套器件的采购需求明确且批量可观，是分销商的直接业务机会。

| 芯片类别 | 需求程度 | 备注 |
|----------|:--------:|------|
| **LPDDR4/LPDDR5/DDR4 内存** | ★★★ | **最高批量品类**。AI推理对内存带宽和容量要求极高，所有产品线标配。优先推荐Nanya南亚科技 |
| AI SoC / NPU（算能/昇腾/寒武纪/海思） | ★★★ | 核心AI算力芯片。**原厂直采，分销商不可触及**。匹配判断时需标记为"需避让" |
| NOR Flash（SPI接口） | ★★★ | 固件存储、启动代码、设备Boot程序，所有嵌入式设备必备 |
| PMU电源管理芯片 | ★★★ | 多路供电、宽压输入、多电压域管理，需工业级宽温(-40~85°C) |
| TVS/ESD保护器件 | ★★★ | 接口防护、EMC合规认证，每路IO口必备。用量稳定单品价值高 |
| eMMC/NAND Flash存储 | ★★☆ | 操作系统和应用程序存储，部分低端产品使用SD卡替代 |
| 以太网PHY芯片 | ★★☆ | 多路网络接口（边缘计算盒子通常需2~4路以太网） |
| WiFi/BT通信模组 | ★★☆ | 物联网场景、WiFi配网、本地维护通道 |
| 4G/5G通信模组 | ★★☆ | 户外/远端边缘计算节点的远程数据回传 |
| HDMI/DP/USB接口芯片 | ★★☆ | 显示屏连接、外设数据接口、调试口 |
| CAN/RS-485收发器 | ★★ | 工业自动化现场通信、PLC对接 |
| 高精度ADC/模拟前端 | ★★ | 传感器信号采集（智慧工业/智慧交通场景） |
| RTC（实时时钟） | ★★ | 边缘设备时间戳记录、离线运行时间同步 |
| 散热风扇驱动 | ★★ | 主动散热方案的高算力边缘服务器 |

> **切入策略核心**（与IT设备和工控类客户有本质区别）：
> 1. **必须区分"核心SoC"与"外围器件"两层供应链**——核心AI SoC为原厂策略直采（算能/昇腾等），是禁区；外围器件（DDR/PMU/Flash/TVS）才是分销商机会。这是AI边缘计算客户区别于传统工控/IT设备客户的关键特征
> 2. **推荐切入顺序**：DDR（最高批量可达BOM成本的15~25%）→ PMU（次高，配合国产化战略）→ Flash（低风险替代，切换成本最低）→ TVS（附件型搭配，多品类覆盖）
> 3. FAE驱动的技术分销模式最为有效——这类客户多为研发驱动型中小企业（50~200人），对FAE技术支持依赖度高，纯价格竞争策略效果有限
> 4. **"全国产化"产品信号（100%纯国产器件）是强采购动机**——已发布全国产化产品的客户，国产品牌外围器件是自然配套方向，应在品牌匹配时优先推荐国产PMU/Flash/TVS品牌
> 5. 决策角色分工：产品总监（CTO级）主导技术选型和平台决定 → 研发团队执行样品测试验证 → 采购部门执行批量下单 → 总经理/老板审批供应商准入
> 6. 销售周期：3~6个月（含技术验证+样品测试+商务谈判）
> 7. 对手盘格局：核心SoC供应商（原厂）不供应外围器件；全球分销商（Arrow/Avnet等）不专注国产配套；本地中小分销商品牌覆盖窄、技术支持弱——这是我方以"品牌覆盖+技术深度"为差异化的切入空间

## 5. 显微成像设备（NEW，2026-08）

> 覆盖：显微镜相机（USB2.0/3.0、HDMI、4K）、电子目镜、显微镜屏显相机（带屏一体机）、数码显微镜（生物/体视）、显微图像软件配套硬件。典型客户为显微成像细分领域的中小微制造商（如宁波天视光电/天视图像、明美光电、图谱光电、鑫图光电）。注意：**此类客户的产品线同时横跨「摄像头类+显示设备+IT周边」三类**，芯片需求按三类交叉匹配（对照字典）。

| 芯片类别 | 需求程度 | 备注 |
|----------|:--------:|------|
| 图像传感器（CIS） | ★★★ | 显微成像核心器件，全产品线必备；中端用格科微/晶相，高端SONY多为原厂直采 |
| 图像处理SoC/ISP | ★★★ | 图像采集与处理核心，Sigmastar星宸摄像头SoC强匹配 |
| 存储芯片（DDR/NOR Flash） | ★★★ | 图像缓存（DDR）+固件存储（NOR Flash），4K/屏显相机DDR需求更高 |
| PMU（电源管理） | ★★★ | 多电压域供电，全产品线通用 |
| USB接口芯片 | ★★★ | 电子目镜/USB相机必备，USB2.0/3.0控制器 |
| WiFi/BT无线模组 | ★★☆ | WiFi电子目镜是差异化卖点，博流/爱科微 |
| HDMI/接口芯片 | ★★☆ | HDMI/4K相机、屏显相机视频输出，Parade谱瑞 |
| MCU微控制器 | ★★☆ | 相机控制、参数配置，恒烁Zbit |
| 显示驱动/背光驱动 | ★★☆ | 屏显相机（7/10.1/11.3寸屏幕），ILITEK/华源智信 |
| 马达驱动 | ★★☆ | 数码显微镜调焦，士兰微 |
| TVS/ESD保护 | ★★☆ | 接口防护，应能微 |

> 切入策略要点：显微成像客户多为10~50人小微制造企业，单体采购额有限（年50~300万元），但**BOM品类多、单价高、小批量多频次**，一次合作可带动多品类销售。推荐切入顺序：存储（DDR+NOR，切换成本低）→ PMU → WiFi模组（绑定WiFi目镜卖点）→ HDMI接口。

## 6. FPV航模/无人机视频影像设备

> 覆盖：FPV穿越机相机（模拟/数字）、数字图传（VTX）、4K运动相机、夜视相机、头盔摄像头、气枪瞄准镜摄像头等航模/无人机视频影像产品。典型客户为狼天科技（RunCam——全球FPV相机TOP3、大疆DJI FPV品类中国总代理）、Caddx、Foxeer、BetaFPV等深圳/珠三角品牌商。详见 `references/fpv-camera-drone-video-customers.md`。

| 芯片类别 | 需求程度 | 备注 |
|----------|:--------:|------|
| CIS图像传感器 | ★★★ | 成像核心；**高端SONY原厂直采不可触**，中端晶相/格科微可切入 |
| 图像处理SoC/ISP | ★★★ | 模拟链路ISP+OSD、数字链路编解码SoC，Sigmastar星宸强匹配 |
| MCU（32位） | ★★★ | 相机控制、参数配置、OSD叠加，恒烁Zbit |
| NOR Flash（SPI） | ★★★ | 固件/启动/OSD配置存储，全产品线必备，**切换成本最低（首推切入）** |
| PMU（电源管理） | ★★★ | 多路供电（sensor/SoC/图传/显示），上海贝岭/应能微 |
| TVS/ESD保护 | ★★★ | 接口防护、EMC合规，应能微 |
| DDR | ★★☆ | 数字图传/4K运动相机图像缓存，Nanya南亚 |
| 图传芯片 | ★★☆ | 模拟5.8G VTX专用芯片；**数字VTX（兼容DJI FPV生态）为专有协议原厂方案，不可触** |
| HDMI/接口芯片 | ★★☆ | 4K相机HDMI输出，Parade谱瑞 |
| WiFi/BT模组 | ★★☆ | App连接/固件升级，博流智能 |
| 5.8G无线SoC | ★★☆ | 模拟图传射频方案，AMICCOM笙科 |
| 音频芯片 | ★★☆ | 运动相机录音 |

> 切入策略要点：①**DJI生态直采禁区**——兼容DJI FPV的数字图传为专有协议原厂方案、高端CIS（SONY）为原厂直采，分销商不可触及；②切入顺序 NOR Flash（切换成本最低）→ PMU → TVS → MCU → DDR（绑定数字图传/4K新品）→ 中端CIS；③这类客户产品迭代快、小批量多频次、新品BOM窗口频繁，FAE技术驱动+多品类打包比单品价格战有效。

## 7. 智能面板/智能家居中控屏（NEW，2026-08）

| 芯片类别 | 需求程度 | 备注 |
|----------|:--------:|------|
| MCU（32位） | ★★★ | 面板控制核心，全产品线必备 |
| NOR Flash（SPI） | ★★★ | 固件/启动/UI资源存储，**切换成本最低（首推切入）** |
| PMU（电源管理） | ★★★ | 多路供电（屏幕/SoC/总线），高端面板必需 |
| TVS/ESD保护 | ★★★ | 接口防护、EMC合规，RS485/KNX/电源口必备 |
| 显示驱动/TDDI | ★★★ | 触摸液晶面板显示与触控，ILITEK奕力 |
| 语音SoC/音频处理 | ★★☆ | 语音中控屏识别与音频，炬芯科技 |
| DDR（DDR3/LPDDR） | ★★☆ | 中控屏系统内存，Nanya南亚 |
| RS485/CAN收发器 | ★★☆ | 智能家居总线通信（RS485），杭州思泰微 |
| WiFi/BT模组 | ★★☆ | App连接/配网/固件升级，博流智能 |
| 继电器/功率器件 | ★★☆ | 灯光/窗帘/插座控制回路，士兰微/应能微 |
| IoT SoC | ★★☆ | 中控屏应用处理器（中低端），博流/杭州国芯 |
| 电子纸驱动IC | ★★☆ | 墨水屏面板（**需E Ink认证，切入前确认**），ILITEK奕力 |

> 切入策略要点：①**AMOLED柔性屏为面板厂直采禁区（三星/京东方），KNX协议核心方案为原厂/专有禁区——不正面竞争，聚焦外围配套器件**（存储/PMU/MCU/TVS/接口/无线）；②高端定位决定**品质与一致性是第一要求**（豪宅/酒店市场）；③决策链常受**品牌体系总部约束**（如法国Léwin→上海总部→广州区域），需「本地执行+总部影响」双线推进；④高端定制小批量多频次，客单价靠品类打包（NOR Flash→MCU→PMU→TVS→显示驱动→语音SoC）而非单品放量；⑤墨水屏驱动IC必须确认E Ink认证状态（见 `references/epaper-display-supply-chain.md`）。详见 `references/brand-system-service-center-customers.md`。

## 使用说明

1. 先确定客户产品属于哪个设备类别（可匹配多个类别），通用品类清单查 `industry-chip-dictionary` 字典
2. 对每个匹配的类别，提取 ★★★（确定）的芯片品类作为**核心推荐**
3. 提取 ★★☆（可能）的芯片品类作为**扩展机会**
4. 综合列出推荐采购的芯片品类清单，并说明匹配逻辑
5. **特殊注意事项**：
   - 医疗器械的BOM变更受NMPA/FDA注册证约束，**供应商切换成本高**——切入策略应从注册影响最小的器件（无线模块/存储/通用无源件）开始，逐步向核心器件渗透
   - 带有医用安规（IEC 60601）认证的隔离/电源芯片替换成本极高，需提供完整的安规认证材料
   - 医疗设备企业通常是研发驱动型采购，对FAE技术支持依赖度高——这反而是中小分销商相比大型分销商的差异化优势
