# 英文名反查与关联实体体系发现（NEW — 2026-08 乐橙智造/Viewsmart案例）

> 实战案例：深圳市乐橙智造有限公司画像。客户为已合作（在供）客户，但自身公开信息极度稀缺（无官网、无财务披露、无报道），且公司名"乐橙"与多个知名/同名实体冲突。本案例通过英文名反查+MAC注册表+域名交叉，成功锁定了实体并发现了关联体系——这是信息稀缺客户的又一个高效突破口。

---

## 一、触发场景

| 信号 | 说明 |
|------|------|
| 公司名与知名品牌撞名 | "乐橙" → 大华Imou乐橙智能家居（杭州华橙）、广州乐橙智能家居、乐橙智造（广东）等干扰项 |
| 中文名搜索被无关结果淹没 | 松散中文关键词在 DDGS 后端几乎全部命中无关内容 |
| 目标实体自身公开信息极少 | 无官网、无报道、无财务披露 → 需要绕过本体找"体系" |

## 二、核心技法

### 2.1 英文名反查（cnverify.com 双因子确认）

**触发**：中文名搜索失败或噪声大，且搜索摘要中偶现英文名线索（如 cnverify 的 "Shenzhen Viewsmart Co., Ltd"）。

**搜索模式**：
- `[公司中文名] Shenzhen ... Co., Ltd`（猜测英文名）
- 直接搜 `cnverify.com [中文名]`（该站对中文公司有结构化英文条目）

**双因子确认规则**：cnverify 条目中 **Legal Representative（法人）** 与 **Founding date（成立日期）** 两个字段必须与中文工商信息完全吻合，才能确认英文名归属。乐橙案例：cnverify 显示法人 Zhong Yi（=钟毅）、成立 2019-12-11（=爱企查数据）→ 完全一致 → 锁定 Shenzhen Viewsmart Co., Ltd = 深圳市乐橙智造有限公司。

> ⚠️ 只吻合一个字段不足以确认——同名公司可能在不同日期成立。双因子缺一不可。

### 2.2 MAC 地址注册表验证量产制造能力

**原理**：生产带网络接口设备（路由器/模组/网关/摄像头）的制造商必须向 IEEE 注册 MAC 地址段（OUI/MA-M/MA-L）。注册记录公开可查，**不依赖工商数据即可确认"客户真的在造货"**。

**数据源**：
- `macvendors.co` — 按公司名反查 MAC 段
- `maclookup.app` — 同上，按段反查公司
- `macaddress.io` — 补充

**搜索模式**：`[英文名] MAC address` 或 `[英文名] macvendors`

**乐橙案例产出**：
- 命中 `88:C9:B3` 段注册给 **Shenzhen Viewsmart Technology Co., Ltd**
- IEEE MA-M 类型 → 可分配约 100 万台设备地址 → 量产规模信号
- 注册地址（南山朗山路华南导航大厦10C）与优智互联/意天科技（南山朗山路同方信息港）同区域 → 关联线索

> 💡 **价值**：MAC 注册是"制造型客户判定"的**独立硬证据**，比经营范围推测更强。发现 MAC 注册后，客户类型判定可直接定"制造型/量产"，无需等待其他佐证。

### 2.3 域名/邮箱域名交叉构建关联实体体系

**三个信号源**：

| 信号 | 乐橙案例 | 发现 |
|------|---------|------|
| 英文品牌名 = 官网域名 | 乐橙智造英文名 Viewsmart = 优智互联官网 viewsmart.cn | 两公司共享品牌资产 |
| 联系邮箱域名 = 另一公司官网域名 | 优智互联邮箱 landerjiang@yippee-elec.com = 意天科技官网 yippee-elec.com | 两公司同一控制人 |
| 官网地址同址/同区域 | 优智互联/意天科技均注册南山朗山路11号同方信息港D栋 | 体系办公集中 |

**构建步骤**：
1. 从任一实体出发，记录英文名、官网域名、邮箱域名
2. 用域名反查：`[域名] 公司 法人` 找出持有该域名的其他主体
3. 比对法人：邮箱域名命中主体与当前主体的法人是否相同（乐橙案例：优智互联法人蒋宜里 = 意天科技法人蒋宜里 → 同一控制人体系确认）
4. 整理为关联实体表写入报告（层级：核心实体 / 关联实体A / 关联实体B）

### 2.4 "单主体小 ≠ 体系小"的评分与销售应用

**陷阱**：仅看目标主体注册资本（乐橙智造仅100万、法人独资）会得出"C级小客户"结论，忽略体系价值。

**正确应用**：
- 评分仍按目标主体实际数据（不虚高），但报告叙事中单独标注"体系级价值"
- 若确认同一控制体系，销售策略升级为**体系级统一供货**：多主体（乐橙智造+优智互联+意天科技）合计采购量远大于单主体
- 决策人地图同时列出各主体法人（乐橙：钟毅 + 体系核心：蒋宜里），P0/P1 分路径接触
- C级已合作客户解读中增加一句："若关联体系确认，可升级为体系级客户维护"

## 四、搜索后端注意事项（本案例复现要点）

- 本案例 web_search 实际为 DDGS 后端（错误信息含 "DuckDuckGo search failed"），偶发超时/连接失败——重试即可，不要因此中断
- web_extract 未配置 provider → 使用"多轮定向搜索+摘要提取"替代（见 chinese-sme-search-strategies.md 第六章）
- 中文松散关键词在 DDGS 下几乎必然失败 → **精确引号公司全称 + 英文名搜索**是主路径
- 爱企查详情页 curl 会被百度安全验证拦截 → 改用搜索引擎摘要获取经营范围/地址数据

## 五、可复用清单（下次遇到同类客户直接执行）

```
1. [中文全称] 搜索 → 若被同名品牌淹没 → 转英文名反查
2. cnverify 双因子（法人+成立日期）确认英文名
3. [英文名] MAC address → 查 macvendors/maclookup → 确认量产能力
4. [英文名] 官网域名 / 邮箱域名 → 反查关联主体 → 构建体系图
5. 排除表：系统列举同名干扰项（不同地域/法人）
6. 报告：单主体评分 + 体系级价值标注 + 体系级统一供货策略
```
