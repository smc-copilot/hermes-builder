# 汽车电子/智能座舱 Tier1 客户画像备忘（NEW，2026-08）

> 覆盖：智能座舱域控制器、信息娱乐系统、液晶仪表、HUD抬头显示、车载屏显示、智能声学、智能驾驶域产品的汽车电子 Tier1 供应商（通常是 A股上市公司核心子公司或大型汽车电子集团）。典型客户：华阳通用电子（华阳集团002906）、德赛西威002920、均胜电子、华阳多媒体等。

## 识别信号

1. **上市公司核心子公司模式**：目标实体（如"惠州华阳通用电子"）是上市公司（如华阳集团002906）的全资/控股子公司，子公司独立公开信息极少，所有财务数据在母公司合并口径披露——见 SKILL.md 第1b步「境内子公司-上市母公司」模式
2. **产品线签名**：官网/企查查简介同时出现「智能座舱域+智能驾驶域」「座舱域控制器」「信息娱乐」「液晶仪表」「HUD」「智能声学」等关键词
3. **国家级资质**：国家火炬计划重点高新技术企业、省级创新型企业
4. **规模信号**：员工3000+人、专利1000+条、注册资本>1亿
5. **客户覆盖主流车企**：蔚来/奇瑞/吉利/比亚迪/理想等

## 核心约束：SoC/MCU 原厂直采禁区

与 AI边缘计算、FPV、IP Camera 客户同理，汽车电子 Tier1 的**核心主控为原厂策略直采，分销商不可触及**：

| 类别 | 原厂直采（需避让） |
|------|-------------------|
| 座舱 SoC | 高通 8155/8295/8775、瑞萨 R-Car、芯驰 X9 系列、地平线征程、英伟达 Orin |
| 车规 MCU | 英飞凌、NXP、瑞萨、芯驰 |
| 智驾 SoC | 地平线、英伟达、Mobileye |

切入定位 = 「车规外围器件国产配套补充层」，不正面挑战主力份额。

## 切入策略

1. **车规认证是硬门槛**：AEC-Q100/Q200 认证 + IATF16949 体系 + PPAP 提交能力。切入前确认我方代理品牌的车规认证状态，备齐 PPAP 文档
2. **从切换成本最低品类起步**：NOR Flash → TVS/ESD → PMU → 存储(DDR/eMMC) → 显示驱动/接口，逐步扩展至「存储+电源+保护」打包方案
3. **决策链路长**：研发技术选型 → 集团采购中心供应商准入 → 子公司董事长/集团高层审批。双线推进（研发技术验证 + 采购商务准入）
4. **销售周期 >6个月**：含车规认证 + 上市公司准入流程，属「高价值、高门槛」客户，需中长期培育
5. **本地化采购**：总部+制造基地集中（如华阳在惠州），通过集团采购中心统一管理，关键物料双供应商（二供政策为补充层定位提供合法性）

## 加分项判断要点

- **加分项1（全国TOP3出货量）**：用第三方数据支撑，如 HUD 用高工智能汽车研究院市占率（华阳约23%国内前列、年出货百万套）。「细分龙头/领军」定性荣誉**不构成**出货量排名证据，须有第三方市占率/排名数据
- **加分项2（行业领军）**：细分领域龙头（智能座舱/HUD 国内前2~前5）可满足，但非「全球龙头」则市场地位维度给16分而非18-20分

## ⚠️ 实控人变更/国资入主窗口（跨领域洞察，2026-08 华阳案例）

对任何大型客户（尤其上市公司），阶段一/风控检索中**必须增加一轮「控制权/股权变更」专项检索**：`[公司名] 控制权 变更 股权转让 实控人`。发现实控人变更/国资入主/并购时，双重解读：

| 维度 | 解读 |
|------|------|
| **机会** | 控制权变更→供应链管理体系重构窗口，是供应商导入的难得时机 |
| **风险** | 过渡期决策链不确定性、国企化管理调整，需在风控提示中标注 |

华阳案例（2026-08-24）：华阳集团实控人拟由邹淦荣等8人一致行动人变更为绵阳市国资委（九洲集团入主），8月18日财联社报道、24日复牌——这是"供应链重构窗口 + 过渡期风险"并存的典型。此类动态时效性极强，报告必须标注采集时间，并在决策人地图注明"决策链在国资入主后可能向国企化方向调整"。

## 案例：华阳通用电子（2026-08，S级 98/110）

- 惠州华阳通用电子有限公司，2002年成立，注册资本1.94亿港元，员工3000+，专利1326条，董事长户广
- 华阳集团（002906.SZ）核心汽车电子主体，集团2024营收101.58亿（+42.33%）、归母净利6.51亿、汽车电子占74.85%
- 产品：座舱域控（高通/瑞萨/芯驰多平台）、信息娱乐、液晶仪表、屏显示、智能声学、智能驾驶域
- 评分：基本面50/55 + 匹配度23/30 + 潜力15/15 = 88基础分 + 加分10（HUD TOP3 +5、领军 +3、国产替代/国资窗口 +2）= 98 → S级
- 切入：车规外围器件国产配套（存储DDR/eMMC/NOR + PMU + TVS/功率），从 Flash/TVS 起步
