# AI边缘计算设备客户销售策略指南

> 用于半导体芯片分销企业向AI边缘计算设备制造商（边缘计算盒子、AI服务器、AI加速卡、AI智能工作站、算法一体机、大模型一体机）进行销售的专项策略指南。

## 客户定义与识别

### 典型客户举例
- 英码科技（EMA）、图为科技、研华科技（边缘AI产品线）、凌华科技（ADLINK）、智微智能、创通联达（Thundercomm）、鲲云科技、金亚太科技等

### 客户识别信号
- 产品线中含"边缘计算盒子""AI边缘服务器""AI加速卡"等关键词
- 核心芯片平台为算能（Sophgo BM1684/BM1688）、华为昇腾（Ascend 310/510）、寒武纪（MLU220/270）、华为海思（Hi3559A等）
- 客户宣称"云边协同""AI算力产品""AI场景化解决方案"
- 目标市场为智慧交通、智慧安防、智慧校园、智慧工地等AI视觉场景

## 双供应链结构分析（核心认知）

这是AI边缘计算客户区别于传统制造型客户的最关键特征：

```
┌──────────────────────────────────────────┐
│         AI边缘计算设备整机厂商          │
├─────────────────┬────────────────────────┤
│  核心层（Layer 1）│  外围层（Layer 2）     │
├─────────────────┼────────────────────────┤
│ AI SoC/NPU      │  DDR内存（LP/标准）     │
│ (算能/昇腾/寒武纪) │  NOR Flash            │
│  └── 原厂直采    │  PMU电源管理          │
│  └── 不可触及    │  TVS/ESD保护          │
│                  │  以太网PHY             │
│                  │  WiFi/BT模组           │
│                  │  4G/5G模组             │
│                  │  └── 分销商可切入      │
└─────────────────┴────────────────────────┘
```

**关键结论**：核心层SoC为禁区，外围层为机会。我方定位应为"外围器件国产配套补充层"，而非"核心SoC供应商"。

## 切入策略

### 推荐切入顺序（从易到难，从高批量到低批量）

| 优先级 | 品类 | 首推品牌 | 理由 | 预估年度批量/单客户 |
|:----:|------|---------|------|:---------------:|
| P0 | **DDR内存** | Nanya南亚 | BOM占比最高（15~25%），所有产品线100%需要，切换成本适中 | 10万~100万人民币 |
| P1 | **NOR Flash** | 恒烁Zbit | 固件存储刚需，切换成本最低（无驱动改动），易破冰 | 3万~30万人民币 |
| P2 | **PMU电源管理** | 上海贝岭 | 多路供电必备，国产替代契合度高，但需FAE验证 | 5万~50万人民币 |
| P3 | **TVS/ESD保护** | 应能微 | 接口保护必需品，单价低但用量大且稳定 | 1万~10万人民币 |
| P4 | **WiFi/BT模组** | 博流智能 | 无线场景扩展需求，增量市场 | 视项目而定 |

### 销售接触路径

```
Step 1: 技术层接触 → 产品总监/CTO（技术选型者）
  提供：FAE技术支持 + 样品 + 规格书对比
  目标：完成技术验证，进入BOM备选列表

Step 2: 采购层对接 → 采购经理（执行者）
  提供：报价 + 交期承诺 + 品质认证
  目标：锁定首批试单

Step 3: 决策层确认 → 总经理/老板（准入审批者）
  提供：公司资质 + 国产替代价值主张 + 长期供应保证
  目标：完成供应商准入
```

### 竞争对手识别与应对

| 竞争角色 | 优势 | 弱点 | 应对策略 |
|----------|------|------|----------|
| AI SoC原厂（算能/昇腾） | 核心SoC深度绑定，提供SDK和参考设计 | 不卖外围器件 | 明确定位"不竞争SoC，补充外围配套" |
| 全球分销商（Arrow/Avnet） | TI等国际品牌供给稳定，全球网络 | 不专注国产器件，FAE分散多行业 | 以国产品牌覆盖宽度和深度差异化 |
| 本地中小分销商 | 灵活供货，价格灵活 | 品牌覆盖窄（通常1~3个品牌），技术支持弱 | 以品牌组合优势（Nanya+Zbit+Belling+InventChip同时覆盖）和FAE能力竞争 |

## "全国产化"信号处理

### 检测方法
搜索关键词：`[公司名/品牌名] 全国产化 纯国产器件 自主可控`

检测目标：客户官网产品页面、产品手册/规格书、新闻报道

### 信号价值
- 已发布"100%全国产化"产品的客户，说明**已经在批量采购国产芯片**，有持续配套需求
- 这比"国产化替代战略"（未来意向）是更强的采购动机信号
- 触发后的动作：在品牌匹配中优先推荐国产芯片品牌，给予切入可行性加分

### 典型话术
"贵司已推出全国产化产品，我们可提供Nanya DDR、上海贝岭PMU、恒烁Flash、应能微TVS等国产配套器件，与贵司国产化战略一致。"

## 场景化产品组合推荐

### 场景A：新客户破冰（首单）
- Nanya LPDDR4 2GB x 100pcs（样品批量）
- 恒烁 Zbit NOR Flash 16MB x 200pcs
- 合计预估：5000~15000元（破冰规模）

### 场景B：技术验证完成后的批量试产
- Nanya LPDDR4 2GB x 1000pcs
- 恒烁 Zbit NOR Flash 16MB x 2000pcs
- 上海贝岭 PMU x 1000pcs
- 合计预估：5万~20万元

### 场景C：深度合作后的全品类覆盖
- DDR + PMU + Flash + TVS + WiFi模组的打包供应
- 合计预估：20万~100万+/年（视客户出货量）

## 风险提示与规避

| 风险 | 严重程度 | 应对 |
|------|:-------:|------|
| 客户SoC平台切换（如从算能切到昇腾）改变外围器件需求 | 中 | 聚焦DDR/Flash/PMU等跨平台通用的品类，降低平台绑定风险 |
| 客户被大厂收购后供应链被集团纳入统一采购 | 低 | 在收购前建立不可替代的技术绑定（定制化FAE支持） |
| 客户自身出货量波动大（项目制为主） | 中 | 不接受大额长账期，控制单笔授信额度 |
| 核心SoC供应商（如算能）开始提供参考设计的配套BOM打包 | 中 | 以更灵活的品牌组合和更低的价格竞争 |
