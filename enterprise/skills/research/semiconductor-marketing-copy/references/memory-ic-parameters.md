# 存储器（DRAM/DDR）专用参数采集与写作框架

> 当文案对象为 DRAM 颗粒（DDR3/DDR4/DDR5、LPDDR 系列）时加载本文件，替代默认 IC 参数模板。
> 来源案例：南亚 NT5AD512M16H4-JR（8Gb DDR4 x16）3D 打印场景推广文案（2026-07）。

## 一、DRAM 专用参数集（技术参数章节必备项）

```
【关键技术参数】
产品型号：完整型号（含速度等级后缀）
容量与组织：XGb（XXXM × 位宽），如 8Gb（512M × 16bit）
产品代际：DDR4 / DDR5 / LPDDR4X 等 + Die 代号（如 H-Die）
数据速率：XXXXMbps（DDR4-XXXX，时钟频率 = 数据速率 ÷ 2）
时序等级：CL 值（tRCD/tRP 若无来源则标注"以官方Datasheet为准"）
供电电压：VDD/VDDQ（DDR4=1.2V）、VPP（DDR4=2.5V）
内部结构：Bank Group × Bank 数、8n/16n 预取
温度等级：商业级（0~95°C Tcase）/ 工业级（-40~95°C）等
封装形式：球数 + FBGA（具体尺寸/球距若分销商页面未披露，列入待核对项）
关键特性：On-die VREFDQ、DBI、写CRC、ODT 等
```

与通用 IC 的本质差异：DRAM 没有"功能框图/外设清单"可写，卖点全部落在**容量组织、速度等级、位宽拼配经济性、温度等级、供货生命周期**五个维度上。

## 二、工程推理模式（把参数转成场景说服力）

1. **带宽计算公式（文案中直接展示计算过程，增强工程可信度）**：
   峰值带宽 = 数据速率(Mbps) × 位宽(bit) ÷ 8
   例：3200Mbps × 16bit ÷ 8 = 6.4GB/s；双颗 32 位 = 12.8GB/s
2. **位宽拼配经济性（x16 vs x8 的选型叙事）**：
   - 单颗 x16 = 16 位总线 + 单颗容量，点对点拓扑，布线/等长设计最简
   - 两颗 x16 并联 = 32 位总线，容量翻倍，BOM 归一为单一料号
   - 嵌入式 SoC 板（16/32 位内存控制器）首选 x16；服务器/模组才用 x8 多颗堆叠
3. **负载带宽估算锚点**：1080p@30fps 原始帧缓冲读写约 370MB/s——AI 视觉/摄像头类场景的带宽压力论证可复用此数字
4. **温度等级 → 环境映射**：商业级 95°C Tcase 上限可论证覆盖"封闭腔体/机箱内局部温升"场景，写作时建议附"预留 Tcase 监测点"的设计建议
5. **供货生命周期叙事（DRAM 独有的强卖点）**：设备类客户（工业设备、3D 打印、安防）平台定型后主板沿用 5~8 年，DRAM EOL 后重新验证替代颗粒的 SI 仿真+认证成本远高于料件本身 → 利基型原厂（南亚、华邦等）的长供货承诺是对抗三大原厂（三星/SK海力士/美光）EOL 风险的核心差异化论点；国内客户可叠加"非美系第二来源"角度

## 三、南亚（Nanya）料号速查

- 前缀：NT5AD = DDR4；NT5CC = DDR3；NT6AN = LPDDR4 类
- 组织段：如 512M16 = 512M × 16bit（8Gb）；末位字母+数字 = Die 代际 + 位宽代码（H4 = H-Die x16）
- 速度后缀：-JR = 3200Mbps / CL22（商业级）；-HR = 2666Mbps（以官网 Part Number Guide 为准）
- 官网产品页 `nanya.com/en/Product/<id>/<型号>` 可确认型号存在性，但参数细节需靠分销商页面摘要交叉提取（web_extract 对其无效时）
- 已验证事实（2026-07 多源一致）：NT5AD512M16H4-JR = 8Gb DDR4 H-Die，512M×16，3200Mbps，1.2V，96-ball FBGA，商业级 0~95°C

## 四、典型应用场景写作模式（嵌入式 DRAM 文案）

| 场景类型 | 叙事切入点 | 关键论证素材 |
|---------|-----------|-------------|
| Linux SoC 主控板（3D打印/网关/HMI） | 架构换代：MCU+SRAM → SoC+GB级DDR | Klipper 类 host 侧运算、G-code/固件缓存、Web 服务并发；1GB 是新一代起点 |
| AI 边缘视觉/质检 | 数据通路：传感器→ISP→帧缓冲→NPU推理 | 370MB/s@1080p30 帧缓冲 + 模型权重/特征图并发压力 |
| 工业设备/设备农场 | 供货连续性权重 > 单价 | EOL 重验证成本、5~8 年平台生命周期、单一料号归一化备料 |

3D 打印领域的行业事实锚点（可复用开头）：主控从 Marlin 8 位/32 位 MCU 方案向"Linux SoC + Klipper/闭源实时固件"迁移，输入整形（Input Shaping）、AI 首层质检、运动前瞻规划全部上移到主控，内存需求从 KB 级 SRAM 跳到 GB 级 DDR。

## 五、检索与降级注意

- DRAM 颗粒的分销商页面摘要（SmartSemi、LCSC、ssfkg、pcxco 等）通常已含完整核心规格（容量/组织/速率/电压/封装/温度），多源摘要交叉一致即可采信写入，无需强求打开 Datasheet 原文
- **搜索结果劣化识别**：若 web_search 返回结果的 title 为空、URL 为 `/clev?event=...` 类跟踪重定向，说明搜索后端临时劣化——不要继续重试消耗额度，若核心参数已多源验证完毕则直接进入写作，缺口列入文末待核对项
- 封装具体尺寸/球距、完整时序组合（CL-tRCD-tRP）、Die 制程节点是分销商摘要最常缺失的三项，默认列入待核对项而非猜测填充
