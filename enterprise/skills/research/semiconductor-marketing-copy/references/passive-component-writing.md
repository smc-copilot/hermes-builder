# 被动元件参数采集与场景写作参考

当文案对象为电阻、电容、电感、连接器等被动元件（非IC器件）时，技术参数体系和应用场景推理逻辑与IC芯片存在显著差异。本文件提供被动元件专用的参数采集框架和场景写作模式。

## 电阻器（Resistor）

### 核心参数集（IC参数模板不适用）

| 参数项 | 说明 | 常见表述 |
|--------|------|---------|
| 阻值 | 标称电阻值 | 如 2.2Ω, 100kΩ |
| 精度/容差 | J=±5%, F=±1%, D=±0.5% | ±5%（J级） |
| 额定功率 | 在指定环境温度下的最大连续功耗 | 1W @ 70°C（须标注降额起始温度） |
| 封装形式 | 英制/公制标注 + 特殊结构说明 | 0805 Wide Terminal（0508），公制2012 |
| 尺寸 | 长×宽×高 | 2.0mm × 1.25mm × 0.55mm |
| TCR（温度系数） | 阻值随温度变化的比率 | ±200 ppm/°C |
| 工作温度范围 | 器件可正常工作的环境温度区间 | -55°C 至 +155°C |
| 材料与工艺 | 厚膜/薄膜/绕线/金属膜 | 厚膜（Thick Film） |
| 特殊特性 | 抗脉冲、抗浪涌、高精度等 | Pulse Withstanding, Anti-Surge |
| 认证 | 车规/安规认证 | AEC-Q200, UL |

### 电阻器关键工程推理模式

- **功率密度对比**：同封装下的额定功率与标准器件对比（如"0805标准封装0.125W vs 宽端子1W，8倍提升"）
- **降额曲线解读**：额定功率在70°C以上需线性降额，到最高工作温度时降为0。应用场景描述须考虑实际工作温度下的可用功率裕量
- **脉冲耐受**：短时过载功率（如10倍额定功率，持续5秒）的承受能力，适用于浪涌限流、启动冲击等场景
- **TCR对系统精度的影响**：全温区最大阻值偏移 = 标称阻值 × TCR × 温度变化幅度，用于论证是否满足系统精度要求
- **封装-功率替代价值**：在更小的封装内实现同等功率，节省PCB面积（如"用0805替代2512实现1W功率"）

### 电阻器常见应用场景模式

1. **浪涌限流**：电源输入端串联电阻，抑制开机/负载突抛瞬态。关注脉冲耐受和AEC-Q200
2. **电流检测（Shunt）**：串联在电流路径中，通过压降检测电流。关注TCR、精度、功率损耗
3. **栅极驱动电阻**：MOSFET栅极串联，控制开关速度、抑制振铃。关注抗脉冲和功率裕量
4. **分压/偏置网络**：为ADC、比较器提供分压或偏置。关注精度和TCR
5. **均流电阻**：并联电源模块输出端串联，实现电流均衡。关注功率损耗和温漂稳定性

## 电容器（Capacitor）

### 核心参数集

| 参数项 | 说明 |
|--------|------|
| 容值 | 标称电容量（如 10μF, 100nF） |
| 额定电压 | 最大直流工作电压（如 25V, 50V） |
| 容差 | M=±20%, K=±10%, J=±5% |
| 介质材料 | MLCC(C0G/X7R/X5R/Y5V)、铝电解、钽电解、薄膜 |
| ESR（等效串联电阻） | 影响纹波电流能力和高频滤波效果 |
| ESL（等效串联电感） | 影响高频去耦性能 |
| 温度特性 | C0G(±30ppm/°C), X7R(±15% over -55~125°C), X5R(±15% over -55~85°C) |
| 封装 | 0201~2220（MLCC常见） |
| 直流偏压特性 | 高介电常数MLCC在直流偏压下容值显著下降（可降50%以上） |
| 认证 | AEC-Q200（车规MLCC） |

### 电容器关键工程推理模式

- **直流偏压降额**：X7R/X5R MLCC在额定电压下容值可能下降30-80%，设计时须按实际工作电压查阅偏压曲线
- **温度特性与介质选择**：C0G适合精密/高频场景，X7R适合通用去耦，Y5V仅适合非关键旁路
- **ESR-纹波电流关系**：P_loss = I_ripple² × ESR，用于评估电容在电源滤波中的发热和寿命影响
- **阻抗-频率曲线**：容抗随频率升高而降低，到谐振点后由ESL主导，决定去耦有效频段

## 电感器（Inductor）

### 核心参数集

| 参数项 | 说明 |
|--------|------|
| 电感量 | 标称值（如 4.7μH, 100μH） |
| 饱和电流（Isat） | 电感量下降至标称值70%时的直流电流 |
| 温升电流（Irms） | 器件温升达到40°C时的直流电流 |
| DCR（直流电阻） | 影响导通损耗和效率 |
| 屏蔽结构 | 屏蔽型/半屏蔽/非屏蔽，影响EMI |
| 工作温度范围 | 如 -40°C 至 +125°C |
| 封装 | 如 6×6mm, 12×12mm |
| 认证 | AEC-Q200（车规功率电感） |

### 电感器关键工程推理模式

- **Isat vs Irms选型**：电感量由Isat决定（防饱和），发热由Irms决定（防过热），两个电流取小值作为设计上限
- **DCR-效率关系**：在DC-DC转换器中，电感DCR直接影响转换效率，η_loss ≈ I²×DCR / P_out
- **尺寸-性能权衡**：同电感量下，更大封装通常意味着更高Isat和更低DCR，但占板面积增加

## 通用写作注意事项

1. **参数来源**：被动元件的参数主要来自DigiKey/Mouser产品页摘要（规格摘要通常包含核心参数）、原厂产品页和Datasheet PDF。DuckDuckGo搜索时，优先从Mouser/DigiKey产品页摘要中提取参数
2. **型号解码**：被动元件型号通常编码了关键参数。如ROHM LTR10EZPJ2R2中：LTR=系列名，10=尺寸代码，EZP=封装/端子类型，J=±5%精度，2R2=2.2Ω。在产品介绍章节中解码型号有助于读者理解BOM选型
3. **封装标注规范**：被动元件存在英制/公制双重标注惯例（如0805英制=2012公制），宽端子电阻还有"反转"标注（0805 Wide Terminal实际为0508）。首次出现时须同时标注两种体系，后续统一使用一种
4. **替代价值叙事**：被动元件推广文案的核心叙事模式通常是"用更小/更便宜的封装实现同等性能"——这与IC文案的"功能/性能提升"叙事有本质区别。工程师选型被动元件时最关注的是：在满足电气性能的前提下，最小化封装尺寸和BOM成本
5. **降额使用**：被动元件的可靠性高度依赖降额使用。文案中描述应用场景时，应计算实际工作条件下的功率/电压/电流裕量，而非简单引用额定值
