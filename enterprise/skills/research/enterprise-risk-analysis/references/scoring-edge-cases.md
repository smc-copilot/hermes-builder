# 风险评估评分边缘案例手册

> 本文档汇总在非标准场景下的维度评分处理模式，是对 `credit-rating-system.md` 的实践补充。

---

## 案例1：非上市公司 — 财务数据严重不透明

**特征**：无公开审计报告，营收/利润数据来自媒体引述或创始人自述，存在口径争议。

**处理原则**：
- 区分「创始人/公司口径」与「第三方测算口径」，优先采信第三方
- 毛利率/净利率若仅有公司口径且无法交叉验证 → 降半级
- 银行授信额度作为正面参考，但授信≠实际放款，不可替代现金流数据
- 供应商账期变化（若可获取）是比利润数字更可靠的财务健康信号

**评分保守度**：默认取维度权重×0.8作为置信度折扣，上限不超过8分（除非有公开审计报告）。

## 案例2：实控人争议作为跨维度风险

**特征**：创始人在社交媒体被禁言、地方政府摸底排查合作、公开言论引发广泛争议。

**维度映射**：
| 风险表现 | 影响维度 | 降分理由 |
|----------|----------|----------|
| 创始人被禁言（违反法律法规） | 合规信用 + 公司治理 | 实控人合规风险直接传导至企业 |
| 国资排查合作情况 | 公司治理 + 舆情声誉 | 政策关系不确定性 |
| 多线作战（200+BU） | 公司治理 + 运营效率 | 管理半径过度扩张 |
| 创始人套现老股 | 财务偿债 + 公司治理 | 信号：创始人自身资金需求/信心 |

**评分联动规则**：若公司治理评分≤3分，舆情声誉自动上限≤3分（治理差→舆情必然是风险）。

## 案例3：并购杠杆与质押风险

**特征**：实控人通过并购贷款收购上市公司控制权，入主后立即质押半数持股。

**识别标志**：
- 质押比例≥所持股份50% → 红标
- 质押时间距入主<6个月 → 加重
- 股价在质押后连续跌停 → 平仓风险信号
- 质押对应市值/收购成本比>1.5 → 杠杆率偏高

**评分影响**：若触发2项以上识别标志，财务偿债维度额外扣1分，公司治理维度额外扣1分。

---

## 案例4：营销烧钱与现金流信号

**特征**：大规模营销投放（春晚、超级碗等），同时进行Pre-IPO融资。

**分析框架**：
- 计算「营销支出/年度利润」比值，>25% → 关注
- 若同时出现供应商账期拉长 → 现金流可能承压
- Pre-IPO融资+老股套现同时进行 → 审慎看待"现金流充足"声明

**评分调整**：若营销支出占比>25% 且 账期明显拉长，财务偿债维度扣1分。

## 案例5：多源数据冲突处理

**场景**：公司口径营收450亿 vs 第三方测算400亿；公司口径净利55.6亿 vs 第三方测算20-32亿。

**规则**：
1. 报告中同时呈现两个口径，标注来源
2. 评分时保守取第三方口径（或口径下限）
3. 在维度分析中明确标注数据存在争议
4. 差距>30% → 该维度最多评7分（数据可靠性存疑本身即风险）

## 案例6：舆情集中爆发日（Convergent Crisis Day）

**特征**：多起互不关联的负面事件在**同一24小时内**集中爆发，形成"多重重击"效应。

**典型信号**（≥3项同时出现即为触发）：
| 信号类型 | 示例 |
|---------|------|
| 创始人/高管被平台处罚 | 微博禁言、账号封禁 |
| 监管/政府层面异动 | 地方摸排合作、签约文章被删、窗口指导 |
| 资本市场剧烈反应 | 关联上市公司跌停、质押预警 |
| 媒体/舆论集中负面 | 多家主流媒体同日跟进报道 |
| 合作关系可见断裂 | 合作伙伴删除信息、合同中止公告 |

**为什么需要特殊处理**：
- 单一事件可能只是"关注级"风险，但3+事件同日爆发产生的**信号共振**远超加和效应
- 市场（资本方、供应商、政府）会将这些信号关联解读为**系统性风险**而非孤立事件
- 这种"暴击日"本身就是**治理失效和公关失控的终局症状**

**评分联动规则**：
- 若确认≥3项同日爆发 → **舆情声誉维度自动上限≤3分**
- 若其中包含资本市场剧烈反应（跌停/质押预警） → **公司治理维度额外扣1分**
- 若其中包含政府/监管异动 → **财务偿债维度额外扣1分**（融资渠道可能收窄）
- 报告中应明确标识该日为"舆情集中爆发日"并在核心摘要的Top 5风险中体现

**与案例2的关系**：案例6是案例2（实控人争议跨维度风险）的**极端加速形态**——当实控人争议持续发酵至引爆多方联动反应时，触发案例6的特殊降级规则。
