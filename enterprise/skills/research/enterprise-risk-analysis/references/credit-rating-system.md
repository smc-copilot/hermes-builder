# 三等九级信用评级体系参考

## 概述

本体系参照国内主流评级机构（中诚信、联合资信、大公国际、新世纪等）的通用标准，结合企业风险评估的11维度框架制定。适用于企业内部授信参考，非正式评级机构评级。

## 等级定义

### 三等九级主标尺

| 等级 | 偿债能力 | 违约风险 | 核心特征 |
|------|---------|---------|---------|
| **AAA** | 极强 | 极低 | 财务极为稳健，行业地位领先，治理规范，无实质合规风险 |
| **AA** | 很强 | 很低 | 财务稳健，行业地位突出，偶有轻微风险但可控 |
| **A** | 较强 | 较低 | 财务健康，行业地位良好，存在可管理的风险点 |
| **BBB** | 一般 | 一般 | 财务基本健康，行业中等水平，存在若干关注事项 |
| **BB** | 较弱 | 较高 | 财务存在压力，行业竞争激烈，有实质风险需关注 |
| **B** | 较差 | 很高 | 财务压力明显，行业下行或竞争弱势，多项风险叠加 |
| **CCC** | 很差 | 极高 | 财务严重困难，存在重大合规或诉讼风险，经营可持续性存疑 |
| **CC** | 严重不足 | 极大 | 基本丧失正常偿债能力，面临重大危机 |
| **C** | 基本不能偿还 | 确定违约 | 已违约或濒临破产清算 |

### 微调符号

每个等级可添加"+"或"-"进行微调：

- **"+"**：在该等级中偏上，接近上一等级
- **"-"**：在该等级中偏下，接近下一等级
- **无符号**：该等级标准位置

示例：AA+ > AA > AA- > A+

### 评级展望

| 展望 | 含义 |
|------|------|
| **正面** | 未来6-12个月内评级可能上调 |
| **稳定** | 未来6-12个月内评级预计不变 |
| **负面** | 未来6-12个月内评级可能下调 |
| **观察** | 存在重大不确定性事件，待进一步信息确认方向 |

## 维度权重体系

### 标准权重分配

| 评估维度 | 权重 | 说明 |
|---------|:---:|------|
| 财务偿债能力 | **20%** | 核心维度：反映直接偿债能力 |
| 合规信用状况 | **15%** | 法律红线：失信/被执行/制裁一票否决风险 |
| 运营效率 | **10%** | 经营质量：反映资金与库存周转效率 |
| 公司治理 | **10%** | 管理风险：实控人/高管/担保/变更 |
| 行业环境 | **15%** | 外部风险：行业周期+政策+技术变革 |
| 供应链安全 | **10%** | 依赖风险：上下游集中度与稳定性 |
| 舆情声誉 | **5%** | 品牌资产：负面事件对经营的影响 |
| 综合偿债保障 | **15%** | 整体判断：多维度综合后的偿债意愿与能力 |
| **合计** | **100%** | |

### 一票否决/降级触发条件

以下情况触发降级或一票否决：

| 触发条件 | 降级幅度 | 说明 |
|---------|:---:|------|
| 失信被执行人（当前有效） | 直接降至BB或以下 | 丧失基本信用 |
| 被执行金额 > 净资产50% | 至少降2级 | 偿债能力严重受损 |
| SDN/实体清单制裁 | 至少降2级 | 业务可持续性受重大威胁 |
| 实控人涉案（刑事） | 至少降2级 | 控制权与企业存续风险 |
| 经营异常满3年未移出 | 直接降至CCC或以下 | 可能被吊销 |
| 持续经营现金流为负（3年+） | 至少降1级 | 造血能力丧失 |
| 资产负债率 > 90% | 至少降1级 | 债务压力极大 |
| 核心客户（>30%营收）流失 | 至少降1级 | 收入断崖风险 |
| 行业遭遇强监管禁令 | 至少降1级 | 外部不可抗力 |

## 各维度评分细则

### 财务偿债能力（1-10分）

| 分数 | 实缴率 | 资产负债率 | 净利率 | 经营现金流 |
|:---:|------|:---:|------|------|
| 9-10 | ≥100%（超缴） | <30% | >行业均值+5pp | 持续为正且增长 |
| 7-8 | ≥80% | 30-50% | 行业均值±5pp | 近3年为正 |
| 5-6 | 50-80% | 50-70% | 行业均值-5pp | 近2年为正 |
| 3-4 | 20-50% | 70-85% | 微利或亏损 | 时有为负 |
| 1-2 | <20% | >85% | 持续亏损 | 持续为负 |

### 合规信用状况（1-10分）

| 分数 | 失信/被执行 | 诉讼/行政处罚 | 经营异常 | 制裁清单 |
|:---:|-----------|:---:|------|:---:|
| 9-10 | 无记录 | 近3年无 | 从未列入 | 不涉及 |
| 7-8 | 无 | 1-2件轻微 | 曾有但已移出 | 不涉及 |
| 5-6 | 无但有1-2件被执行 | 3-5件 | 列入但已移出 | 不涉及 |
| 3-4 | 曾列入失信（已移出） | 5-10件或重大处罚 | 当前列入 | 间接关联 |
| 1-2 | 当前失信或大量被执行 | >10件或严重处罚 | 严重违法失信 | 直接涉及 |

|:---:|:---:|:---:|

| 3-4 | 90-180天 | 2-4次/年 |
| 1-2 | >180天 | <2次/年 |

### 公司治理（1-10分）

| 分数 | 法人稳定性 | 对外担保 | 融资能力 |
|:---:|------|:---:|------|
| 9-10 | 3年无变更 | 无对外担保 | 顶级机构，多轮融资 |
| 7-8 | 2年无变更 | <净资产10% | 知名机构，顺利融资 |
| 5-6 | 有变更但平稳过渡 | 10-30% | 有融资但估值一般 |
| 3-4 | 频繁变更 | 30-50% | 融资困难或长期未融资 |
| 1-2 | 混乱/实控人涉案 | >50%或连环担保 | 无法融资 |

### 行业环境（1-10分）

| 分数 | 行业周期 | 政策环境 | 技术威胁 |
|:---:|------|:---:|:---:|

| 5-6 | 成熟期，增速放缓 | 政策中性 | 有替代技术但非颠覆性 |
| 3-4 | 下行期或过度竞争 | 政策趋严/有抑制 | 颠覆性技术出现 |
| 1-2 | 衰退期 | 强监管/禁令/制裁 | 技术已被替代 |

| 分数 | 质量事故 | 投诉/召回 | 负面舆情 |
|:---:|------|------|------|
| 9-10 | 无 | 无 | 近2年无重大负面 |
| 7-8 | 偶有轻微 | 个别投诉 | 偶有争议但未发酵 |
| 5-6 | 有中等事件但已解决 | 局部投诉 | 有过负面热点但已平息 |
| 3-4 | 重大事故未完全解决 | 大规模投诉/局部召回 | 持续负面舆情 |
| 1-2 | 反复事故/造成人身伤害 | 全国性召回/集体诉讼 | 品牌严重受损 |

## 评级调整步骤

### Step 1：各维度独立评分（1-10分）

基于搜索结果，对照上述评分细则逐维度打分。

### Step 2：加权计算总分

```
加权总分 = Σ(维度得分 × 权重)
```

### Step 3：触发条件检查

检查一票否决/降级触发条件，如有触发，按规则下调。

### Step 4：确定最终等级

将调整后的总分映射到信用等级。

### Step 5：确定评级展望

| 条件 | 展望 |
|------|:---:|
| 近期有明确正面催化剂（如大额融资、政策利好、业绩拐点） | 正面 |
| 近期有明确负面催化剂（如诉讼发酵、核心客户流失、行业下行） | 负面 |
| 存在重大不确定事件（如并购审批、IPO结果、制裁审查） | 观察 |
| 无显著变化预期 | 稳定 |
