# B2B电子元器件分销业务——分析语境与评估标准

## 为什么B2B与B2C的评估标准完全不同

B2B电子元器件分销的本质是**供应链服务**，而非零售。客户购买的是：
- 供货稳定性（非缺货）
- 料号准确性和可追溯性
- 账期和信用支持
- 工程支持和替代料建议

因此客户一旦建立采购关系，**天然倾向于复购**（切换成本高）。复购率高是B2B的常态，而非B2C中的"优秀"信号。

## 关键指标基准（2023-2024年标准）

### 复购率基准

| 阶段 | 合理范围 | 说明 |
|------|----------|------|
| 成熟分销商（运营3年+） | 70-85% | 年度客户留存率 |
| 初创成长（第2-3年） | 60-65% | 剔除<$100样品单后 |
| 初创早期（第1年） | 40-55% | 仍在积累客户阶段 |
| **本部门当前（第2年）** | **56%（含样品单）→约60-65%（剔除后）** | 略低于理想线 |

### 一次性客户诊断

B2B中一次性客户（首单后不复购）需要分层分析：

| 类型 | 首单金额 | 比例容忍度 | 诊断方向 |
|------|----------|-----------|----------|
| 样品/开发板询价 | <$100 | 容忍度较高 | 正常现象，不构成流失 |
| 中等询价 | $100-$1K | <50% | 可能价格/交期/服务不匹配 |
| 高价值未转化 | >$1K | <20% | **严重信号**，需复盘原因 |

### 销售人效基准（B2B纯线上分销）

| 档次 | 人均年产出 | 评估 |
|------|-----------|------|
| 优秀 | >$200K | 团队效应成熟 |
| 良好 | $120K-$200K | 本团队当前水平 |
| 需提升 | $50K-$120K | 人均产出不足 |
| 低效 | <$50K | 需评估是否适合销售岗 |

### 客户集中度基准（B2B分销）

| Top3占比 | 评估 | 说明 |
|----------|------|------|
| <50% | ✅ 健康 | 客户多元化充分 |
| 50-70% | ⚠️ 需关注 | 正常范围，但需监控 |
| 70-85% | 🔴 偏高 | 初创企业常见，须主动降低 |
| >85% | 🚨 危险 | 单一客户依赖，须立即行动 |

**注意：** 上述基准需先剔除机会性/一次性大额收入后再计算。

## 团队分析的"归属规则陷阱"

### 基本规则
- B2B业务中经常出现：跨部门协作、总部分配客户、海外办事处配合
- **永远不要假设数据中的sales_person字段就是正确的业绩归属**
- 必须在Phase 0主动询问归属规则

### 典型场景
```
数据中显示：销售A处理了30单小单（$23K），而销售B处理了日本大客户（$212K）
实际情况：日本业务是由销售A与海外办事处合作完成的，一半归销售A
→ 修正后：销售A的实际贡献为$23K + $106K = $129K
→ 如果未修正，会错误判断销售A为"只做小单的低效销售"
```

## 机会性收入 vs 有机增长

### 机会性收入特征
- 单一来源、一次性、无复购记录
- 通常需要特殊渠道/关系/授权
- 金额通常占年收入的20-40%
- 代表：总部分配的客户、海外机遇订单、一次性项目备货

### 有机增长特征
- 线上获客、逐步放量（$270→$1K→$10K→$48K）
- 复购可预期（规律性下单）
- 模式可复制（多个客户走同路径）
- 代表：上海卓岚模式、清远冰恒物联模式

### 处理策略
1. 先计算含机会性的总业绩（给管理层看整体）
2. 再计算剔除后的核心有机增长（给自己做运营评估）
3. 机会性收入剔除后，团队的真实增长往往更陡峭
4. 报告的叙事应围绕核心有机增长展开，机会性收入作为备注
