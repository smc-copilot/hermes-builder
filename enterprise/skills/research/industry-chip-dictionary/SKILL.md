# 行业-芯片品类字典（Industry-Chip Dictionary）

38 个电子/半导体下游行业 × 完整芯片品类清单。本字典是**行业-芯片品类对照的独立数据资产**，所有 skill 统一通过本字典获取行业↔品类映射。授权品牌×品类对照为独立数据（另行维护），不在本字典中体现。

## 定位与边界

| 做（Do） | 不做（Don't） |
|---------|--------------|
| 行业 → 芯片品类 正向查询（38 类） | 不做品牌匹配（授权品牌×品类对照为独立数据，另行维护） |
| 品类 → 行业 反查（哪些行业用某品类） | 不做客户分析、不产出报告 |
| 行业指纹品类识别（判断客户行业归属） | 不推断具体客户需求（那是调用方的事） |
| 行业覆盖子领域说明（边界澄清） | 不擅自增删行业（须用户/业务方确认，走维护规范） |

**维护规则（强制）**：
1. 本字典是**行业-芯片品类对照的唯一权威入口**，独立维护
2. 行业/品类增删、范围说明调整须用户/业务方确认后更新，并在上表追加版本记录
3. 授权品牌×品类对照为独立数据，与本字典解耦；两者互不派生
4. 调用方每次实时加载，不缓存，避免使用过期版本
5. **大版本维护方法**（扩充行业清单 / 全量完善芯片品类）见 `references/b-table-maintenance-methodology.md`：行业分类检索锚点（WSTS/GB-T 4754/客户画像证据）、向后兼容扩充规则、双 Agent 交叉审查 + 总监融合裁决、高频遗漏品类速查
