# 半导体分销企业业务数据分析方法论

## 触发条件

- 用户提供**汇总级**经营数据（多客户/多产品/多区域），要求「业务/经营分析」「经营体检」「复盘」「销售/利润/客户分析」「经营诊断」
- 用户给出经营指标（营收、毛利、库存、应收、DIO/DSO/CCC、HHI等），要求全面分析或异常定位
- 需要从数据到诊断报告的结构化输出（口径声明→快速体检→核心看板→维度深度→归因→风险→行动建议）

## 定位与路由（P0）

**本skill**：汇总级经营数据全面分析（多客户/多产品/多区域体检诊断）

**路由至专用skill**：

| 数据类型 | 路由目标 |
|---------|---------|
| 交易级流水CSV/TSV | `sales-transaction-diagnostics` |
| 单一客户画像 | `customer-profiling` |
| 单一原厂评估 | `manufacturer-profiling` |
| 销售个人客户群 | `sales-rep-portfolio-analysis` |
| 客户群专项（HHI/金字塔/增长动能） | `sales-rep-portfolio-analysis`（个人）/ `sales-team-portfolio-analysis`（团队） |
| 库存深度诊断 | `inventory-turnover-analysis`（⚠️未安装：由本skill §1.3直接覆盖） |
| 财务报表P&L | `financial-statement-analysis`（⚠️未安装：由本skill §2.1/§1.4直接覆盖） |
| 企业风险/贸易合规 | `enterprise-risk-analysis` / `trade-compliance-analysis` |

**触发**：「业务/经营分析」「经营体检」「复盘」「销售/利润/客户分析」+汇总级数据

## 核心原则

1. **数据驱动（P0）**：先画像→选路径→出结论；数据有什么分析什么
2. **六维覆盖**：客户/产品/库存/现金流/供应链/区域渠道，缺失标"数据不可用"
3. **指标联动**：单一指标不孤立判断（毛利率+GMROII+CCC联判）
4. **量价分离**：ΔRev=ΔQ·P₀+ΔP·Q₀+ΔQ·ΔP（无数量数据降级为金额对比）
5. **双口径必算**：HHI/帕累托/占比→营收+毛利
6. **因果分层**：L1相关→L2量价→L3结构→L4因果，不跳层；每归因配证伪
7. **统计标注**：样本不足→降级+标可信度
8. **合规前置**：受管制物项→先合规后商业，一票否决
9. **角色适配**：CEO看战略·销售看效能·财务看P&L+CCC·供应链看上游
10. **软信号**：高毛利+应收膨胀="以赊换量"·新客加速+客均降=质量下滑·Allocation主动变被动=地位下滑·人均客户↑+产出↓=超载

## Phase 0：数据画像（强制·跳过=最大反模式）

**60秒画像**：格式→规模(行×列)→粒度(交易/汇总/混合)→可用维度(✅⚠️❌)→质量(币种/含税/空行/成本完整度/时间范围)

**复杂度分级**：

| 等级 | 规模 | 策略 |
|:----:|------|------|
| S极简 | 3-10行×3-5列 | 仅覆盖维度，1-3方法，3-5条发现 |
| M标准 | 10-100行×5-15列 | 选2-3维度做深，3-5方法 |
| L丰富 | 100-1000行×10-30列 | 全覆盖+跨维度交叉，5-8方法 |
| XL海量 | >1000行或>30列 | 先异常筛选再深挖（优先路由） |

**聚焦**：最显著异常>用户问题>框架标准项 · 密度>完整（每发现含量化+含义+动作） · 未覆盖维度标盲区+标置信度

## 一、六大分析维度

### 1.1 客户维度
| 分析项 | 核心指标 | 公式/定义 |
|--------|---------|----------|
| 客户价值 | RFM综合评分 | R=最近下单间隔, F=次数, M=**毛利贡献额**（⚠️非营收） |
| 活跃度 | 活跃/沉默/流失率 | 活跃=90天内有单, 沉默=90-180天, 流失=>180天 |
| 集中度 | HHI+CR1/CR3 | HHI=Σ(sᵢ²)×10000；CR1≤30%🟢 CR3≤50%🟢 HHI<1800🟢 1800-2500🟡 >2500🔴 |
| 钱包份额 | SOW | =我司销售额/客户总采购额_est |
| 分层 | 四层 | 🏆战略标杆/⭐核心大/📊成长中/📦小微长尾 |
| 生命周期 | 四阶段 | 培育(<1年)/放量(1-3年)/成熟(>3年)/衰退(下滑) |
| 获客效率 | CAC/CLV | CAC=获客成本/新客数, CLV=客均年毛利×预期年限 |

**RFM自适应**：≥50客户→四分位·20-49→三分位·<20→固定阈值 · M必须用毛利额

**HHI阈值差异**：客户端阈值宽于原厂端（分销天然集中 vs 断供风险更致命需更严多元化）

### 1.2 产品维度
| 分析项 | 核心指标 | 公式/定义 |
|--------|---------|----------|
| 物料结构 | 品类/SKU分布 | 按产品线/品类/价格带的销售额+毛利占比 |
| 重点产品 | 帕累托集（双口径） | 营收降序累计≥80% AND 毛利降序累计≥80%，取交集 |
| 盈利能力 | GMROII | =毛利率×库存周转率=毛利/平均库存成本 |
| 单位经济 | 单位毛利/费用 | SKU级(单价-成本)；变动费用=变动费用总额/销量 |
| 量价分解 | 收入增长拆解 | ΔRev=ΔQ·P₀+ΔP·Q₀+ΔQ·ΔP |
| 生命周期 | Design-in漏斗 | design-in→win→sample→trial→mass production |
| 主控切入率 | 主控项目占比 | 主控芯片项目数/总design-in数 |

### 1.3 库存维度
| 分析项 | 核心指标 | 健康基准 |
|--------|---------|---------| 
| 周转天数 | DIO | 授权<60天🟢 60-90🟡 >90🔴；独立<90🟢 90-120🟡 >120🔴 |
| 周转率 | ITR=COGS/平均库存 | >6次/年🟢 4-6🟡 <4🔴 |
| 呆滞 | 库龄>180天占比 | >15%🔴 |
| 库龄结构 | 四段分布 | 0-60/61-120/121-180/>180天各占比 |
| 跌价风险 | 准备充足率 | 市价<成本SKU的准备覆盖率 |
| GMROII | 毛利回报率 | >120%🟢 80-120%🟡 <80%🔴 |

**库存×产品联动**：高GMROII+高库存=加仓·高GMROII+低库存=补货·低GMROII+高库存=减仓

### 1.4 现金流/资金维度
| 分析项 | 核心指标 | 健康基准 |
|--------|---------|---------| 
| DSO | AR/(Sales/365) | <60天🟢 60-90🟡 >90🔴 |
| DPO | AP/(COGS/365) | 与DSO+DIO协调，不极端拉长 |
| **CCC** | DSO+DIO-DPO | −30至60天🟢（含理想负CCC） 60-90🟡 >90天或<−30天🔴 |
| 应收敏感度 | (ΔAR/AR)/(ΔSales/Sales) | ≤1🟢 >1持续2期🟡 >1.5或持续3期🔴 |
| 回款率 | 当月实收/当月应收 | ≥90%🟢 80-90%🟡 <80%🔴 |
| 超期应收 | 超30天应收/总应收 | ≤10%🟢 10-15%🟡 >15%🔴 |
| 坏账率 | 实际坏账/总应收 | <0.5%🟢 0.5-1%🟡 >1%🔴 |

**CCC**：每压缩10天≈释放日均COGS×10天；优先序①DSO②DIO③DPO · 0至−30天=理想（占用供应商资金）；<−30天=危险（原厂可能缩减allocation）

### 1.5 供应链/上游维度
| 分析项 | 核心指标 | 健康基准 |
|--------|---------|---------| 
| 原厂集中度 | Top3采购占比 | ≤60%🟢 60-70%🟡 >70%🔴 |
| 原厂HHI | 采购端HHI | <1000🟢 1000-1800🟡 >1800🔴 |
| Allocation | 获配/申请 | ≥90%🟢 70-90%🟡 <70%🔴 |
| 关系层级 | 分级 | 战略/授权/优先/一般/无授权 |
| Design-in管线 | 在推项目 | 按阶段分布 |
| 返点达成 | 目标达成率 | 季度/年度进度 |
| 合规状态 | 受管制物项审查 | 0未处理🟢 有在审🟡 有违规🔴 |

**软信号**：Allocation从主动变需申请→地位下滑（领先财务6-12月）；原厂直销占比提升→去中介化加速

### 1.6 区域/渠道维度
| 分析项 | 核心指标 | 公式/定义 |
|--------|---------|----------|
| 区域分布 | 区域占比/区域HHI | Σ(区域占比²)×10000 |
| 渠道分布 | 渠道占比/毛利率 | 直销/代理/电商各占比及毛利 |
| 区域效率 | 人均产出/ROI | 区域销售/人员数；区域毛利/投入 |
| 渠道效率 | 获客成本/转化率 | 营销费/新客数；成交/线索 |
| 增长分化 | 区域同比/环比 | 各区域增长时间序列 |
| 健康度 | 依赖度/冲突率 | Top1渠道<40%🟢；跨渠道重叠比例 |

区域×渠道矩阵识别效率差异·单区域>50%或单渠道>40%预警·增长率分化识别新兴/衰退市场

## 二、五类经营能力评价框架

### 2.1 盈利能力
| 指标 | 公式 | 基准 |
|------|------|------|
| 毛利率 | (营收-COGS)/营收 | 授权15-25%🟢 独立5-15%🟢 |
| 净利率 | 净利润/营收 | >5%🟢 2-5%🟡 <2%🔴 |
| 销售费用率 | 销售费用/营收 | <8%🟢 8-12%🟡 >12%🔴 |
| GMROII | 毛利率×周转率 | >120%🟢 80-120%🟡 <80%🔴 |
| EVA | NOPAT-资本成本×投入资本 | >0🟢 <0🔴 |
| DOL | EBIT变动率/营收变动率 | 量化固定成本风险 |

### 2.2 发展能力
| 指标 | 公式 | 判断逻辑 |
|------|------|---------| 
| 销售额增长率 | (本期-上期)/上期 | 量价分解：ΔRev=ΔQ·P₀+ΔP·Q₀+ΔQ·ΔP |
| 毛利增长率 | 同上 | 毛利增速<销售增速→盈利质量下降 |
| 客户增长率 | 新客/期初客户 | 区分有机vs并购 |
| 新品导入率 | 新SKU/总销售 | 组合更新速度 |
| 新赛道渗透 | 新行业/总销售 | 多元化进展 |

**增长质量**：高质量=销售增+毛利稳升·低质量=销售增+毛利降（走量）·毒性=销售增+净毛利降（虚胖）

### 2.3 运营能力
| 指标 | 公式 | 基准 |
|------|------|------|
| 人均销售额 | 总销售/销售人数 | 按业务线校准 |
| 人均毛利 | 总毛利/销售人数 | 更反映真实贡献 |
| 管理半径 | 活跃客户/销售人 | 15-25家🟢 25-30家🟡 >30家🔴 |
| 订单效率 | 月均订单/后台人 | 中后台效能 |
| Design-in转化率 | design-win/design-in | >25%🟢 15-25%🟡 <15%🔴 |

### 2.4 风控能力
| 指标 | 公式 | 基准 |
|------|------|------|
| 应收逾期率 | 超期/总应收 | ≤10%🟢 10-15%🟡 >15%🔴 |
| 坏账率 | 坏账/总应收 | <0.5%🟢 0.5-1%🟡 >1%🔴 |
| 汇率敞口 | 未对冲外币/净资产 | <20%🟢 20-40%🟡 >40%🔴 |
| 合规风险 | 未审查数 | 0🟢 >0🔴（一票否决）|
| 集中度风险 | HHI+CR1+CR3 | 见§1.1 |
| 跌价风险 | 呆滞占比 | 见§1.3 |

### 2.5 供应链能力
| 指标 | 公式 | 基准 |
|------|------|------|
| 原厂集中度 | Top3采购占比 | ≤60%🟢 60-70%🟡 >70%🔴 |
| Allocation | 获配/申请 | ≥90%🟢 70-90%🟡 <70%🔴 |
| 预测准确率 | 1-|实际-预测|/实际 | >80%🟢 60-80%🟡 <60%🔴 |
| 交付及时率 | 按期/总订单 | >90%🟢 80-90%🟡 <80%🔴 |

## 四、十种分析方法

### 方法1：对比分析
| 类型 | 场景 | 注意 |
|------|------|------|
| 同比YoY | 消除季节性 | ⚠️春节移位(1-2月合并)、闰年、基数效应 |
| 环比MoM | 短期动量 | 受季节性支配，需配合季节调整 |
| 目标对比 | BP进度 | 目标合理性需前置审查 |
| 标杆对比 | 行业/竞对 | 口径一致性 |
| 内部对比 | 团队/区域/产品间 | 控制混杂因素 |

### 方法2：趋势分析
| 技术 | 条件 | 方法 |
|------|------|------|
| 移动平均 | 平滑波动 | MA(3)或MA(6) |
| 季节性分解 | ≥24月 | STL或X-13ARIMA（<24期禁止季节性结论） |
| 趋势检验 | 显著性 | Mann-Kendall(非参数) |
| 量价分离 | 收入归因 | ΔRev=ΔQ·P₀+ΔP·Q₀+ΔQ·ΔP |

### 方法3：占比分析
客户/产品/区域/渠道的销售额+毛利额占比；帕累托(前N%贡献)。**双口径必算**：营收+毛利

### 方法4：四象限分析
| 组合 | X轴 | Y轴 |
|------|-----|-----|
| 客户价值×成长 | RFM | 同比增长率 |
| 产品效率 | 库存周转率 | GMROII |
| 区域投入产出 | 区域销售 | 区域毛利率 |
| 客户金额×频次 | 累计交易额 | 下单频次 |

阈值：≥50样本→中位数·20-49→均值·<20→业务固定阈值

### 方法5：RFM分析
见§1.1。M用**毛利额**非营收·R用最后下单日·赋分后合并为4-6个业务层级·自适应：≥50→四分位·20-49→三分位·<20→固定阈值

### 方法6：漏斗转化
| 阶段 | 🟢 | 🟡 | 🔴 |
|------|:---:|:---:|:---:|
| Design-in→Win | >25% | 15-25% | <15% |
| Win→Sample | >50% | 30-50% | <30% |
| Sample→Trial | >40% | 20-40% | <20% |
| Trial→Mass | >30% | 15-30% | <15% |
| 全漏斗 | >5% | 2-5% | <2% |

按原厂/产品/销售/行业拆解识别瓶颈

### 方法7：队列分析
按获客时间/渠道/行业追踪留存率、LTV、CAC回收期。区分"留存客户增长"与"全体客户增长"

### 方法8：敏感性分析
| 变量 | 幅度 | 影响 |
|------|------|------|
| 汇率 | ±5%/±10% | 毛利、CCC、外币应收 |
| 原厂涨价 | +5%/+10% | 毛利率、库存价值 |
| 大客户流失 | Top1/Top3 | 营收、利润、HHI |
| 库存跌价 | -10%/-20% | 利润、呆滞损失 |

### 方法9：异常检测
| 类型 | 方法 | 处理 |
|------|------|------|
| 价格偏离 | 同类均价>2σ | 排查折扣/错价/汇率 |
| 数量突变 | 环比>50% | 排查大单/一次性/错误 |
| 回款延迟 | DSO突增>20天 | 逐客户排查信用 |
| 行为突变 | 频率/品类/金额显著变化 | 流失预警或升级信号 |

⚠️ 标记不删除——异常可能是最有价值的信息

### 方法10：归因分析（分层）
| 层次 | 方法 | 置信度 |
|------|------|-------|
| L1 相关性 | 相关系数、趋势同向 | 低 |
| L2 量价分解 | ΔRev=ΔQ·P₀+ΔP·Q₀+ΔQ·ΔP | 中 |
| L3 结构归因 | 固定权重毛利率分解 | 中高 |
| L4 因果推断 | DAG+混杂控制+反事实 | 高 |

**毛利率归因**：ΔGM=Σ(wᵢ₀·Δgmᵢ)[价格/成本]+Σ(Δwᵢ·gmᵢ₀)[结构]+Σ(Δwᵢ·Δgmᵢ)[交叉]·证伪：结构效应<20%→"毛利率降因结构变动"被证伪

## 五、场景导航

| 角色 | 核心关注 |
|------|---------| 
| CEO | 赛道布局、集中度、CCC、风控红线 |
| 销售总监 | 人均产出、客户分层、增长动能、Design-in管线 |
| 财务总监 | 毛利率趋势、CCC三指标、费用率、坏账 |
| 供应链总监 | Allocation、库存周转、呆滞、合规 |
| 运营总监 | 人均效能、流程效率、异常检测 |

| 场景 | 分析路径 |
|------|---------| 
| 月度/季度/年度复盘 | 全维度快扫→异常→重点深挖→归因 |
| 客户/利润/资金/库存/增长 | 对应维度→方法组合→归因 |

## 六、数据质量规则

> ⚠️ 跳过数据质量检查是90%分析错误的根源。

**口径确认**：币种统一(惯例USD)·不含税·成本完整度≥70%(授权成本可能保密MNAR标估算)·粒度(交易/汇总)·时间范围≥12月

| 方法 | 最小样本 | 降级方案 |
|------|---------|---------| 
| RFM四分位 | ≥50客户 | 三分位或固定阈值 |
| 季节性分解 | ≥24月 | 仅报同比+MA |
| 回归 | N≥10×协变量 | 收缩估计/降维 |
| 生存分析 | ≥10事件/协变量 | 削减或KM单变量 |
| 多重比较 | >20项强制 | FDR(BH)校正 |
| 趋势MK | ≥12期 | 描述性趋势 |
