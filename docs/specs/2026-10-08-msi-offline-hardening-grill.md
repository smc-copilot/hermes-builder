# MSI Offline Hardening — Grill Summary

> Generated by grilling on 2026-10-08. Status: decisions resolved, not yet planned.

## Target

`docs/prd/PRD-HERMES-BUILDER-MSI-OFFLINE-HARDENING-v1.0.md`（状态 REVIEW）。对照当前安装器：per-user MSI、`InstallFiles` 之后的 deferred `InitializeHermes`、`scripts/Initialize-Hermes.ps1` 仍调用上游 `install.ps1 -Stage node-deps`，并在 `relocatable=true` 时只留下 `bin\hermes.cmd`。桌面探针要求 `bin\hermes.exe`。

## Resolved Decisions

| Decision | Resolution | Rationale |
|----------|-----------|-----------|
| 第一版发布门槛 | 只批 Phase 1 | 全文 22 项验收里，EarlyPreflight、全量哈希、T0 快照、COMMITTED 写入者仍没有唯一做法。按 PRD 自己的 No-Inference 规则，全文不能标 `APPROVED_FOR_PLAN`。 |
| Phase 1 范围 | 固定源码 SHA；`uv` 之后立刻验 CLI；必须有 `bin\hermes.exe`；安装阶段不再调用上游 `node-deps` | 这是已经在本机复现过的桌面 `RUNTIME_INVALID` 与目录被掏空问题，能单独收口。 |
| 终端 Node | 不跑 `npm` | Browser Use、CUA、TUI 与 Chromium 留到后续阶段。Phase 1 只交付 Python CLI 和 `bin\hermes.exe`。 |
| 启动器形态 | `pyvenv.cfg` 出现 `relocatable=true` 则安装失败 | 该分支今天会删除 `bin\hermes.exe` 并只写 `.cmd`。桌面探针要 exe。Phase 1 只接受从 `venv\Scripts\hermes.exe` 复制出的 exe。 |
| 目录被改名 | 缺 `pyproject.toml` 即失败 | 不恢复、不删除 `hermes-agent.broken-*`、不 `git clone`。修复交给 MSI。 |
| CLI 验收 | 两处 `--version` 都等于锁定的 `0.21.0` | 先跑 `venv\Scripts\hermes.exe --version`，复制后再跑 `bin\hermes.exe --version`。两次一致后才写成功标记。 |

## Contradictions Surfaced

- PRD 验收看的是 `venv\Scripts\hermes.exe`；桌面与 Phase 1 要求 `bin\hermes.exe` 能 `--version`。Phase 1 以桌面探针为准。
- PRD 禁止删除 `.broken-*`，没有禁止 `Install-Repository` / `git clone`。Phase 1 禁止恢复、禁止删除、禁止克隆。
- 当前 `Initialize-Hermes.ps1` 仍调用 `node-deps`、仍会把 `.broken-*` 改回原名，并在 relocatable 时接受 `.cmd`。这些与 Phase 1 冲突，留到实现时改，本次不改代码。
- 全文 22 项一次过关与 Phase 1 切片冲突。发布门槛以 Phase 1 为准，全文保持 REVIEW。

## Assumptions Audited

- 桌面第一版只靠 `bin\hermes.exe` 通过运行时探针 → held。Node 工具不在 Phase 1。
- `uv sync` 默认不把 venv 标成 `relocatable=true` → flagged risky。一旦标上，Phase 1 会整次失败，直到构建把该标志钉死。
- MSI 修复能把被改名搬走的 `hermes-agent` 拷回原路径 → flagged risky。失败策略依赖它，修复行为本次没有验证。

## Open Questions

- `msiexec` 修复遇到原目录已被改名为 `hermes-agent.broken-*`、原路径只剩空的 `.git` 时，是否会把组件文件写回原路径。
- `--version` 输出是整行 `Hermes Agent v0.21.0` 还是只含 `0.21.0`。Phase 1 要求与锁定版本一致，匹配规则留到实现计划里写死。

## Out of Scope

- `COMMITTED` 由谁在 `msiexec` 返回 0 之后写入。
- 全量文件 SHA256 与关键文件集的二选一。
- 安装前 T0 快照的范围与 8GiB 空闲门槛。
- 「零网络尝试」是否计入 `msiexec`、CRL、OCSP、SmartScreen。
- Chromium、Browser Use、CUA、`ui-tui` 的离线安装。
- 所有权账本与 `MANAGED_CONTENT_DRIFT` / `OWNERSHIP_UNKNOWN` 的错误码对齐。
